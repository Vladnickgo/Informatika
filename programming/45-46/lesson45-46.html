1

Теоретичні відомості

1.1 Інтерфейс редактора Scratch 3.0

Середовище Scratch 3.0 побудоване за принципом конструктора: команди об'єднані у кольорові категорії, а алгоритм збирається шляхом з'єднання блоків між собою. Чітке розуміння розташування основних зон інтерфейсу дозволяє швидко знаходити потрібні інструменти та пояснювати будову вікна учням початкової школи.

1.2 Створення, редагування та збереження проєкту

Новий проєкт створюється командою Файл → Новий (або File → New). Для збереження результату на локальний диск використовують команду Файл → Вивантажити на ваш комп'ютер, після чого формується файл формату .sb3. Щоб продовжити роботу над збереженим проєктом, виконують Файл → Завантажити з вашого комп'ютера.

📁 Пам'ятка: культура іменування файлів та проміжне збереження

Надавайте файлам зрозумілі імена без пробілів і випадкових символів, наприклад PR10_Prizvyshche.sb3. Зберігайте проміжну версію проєкту після кожного завершеного етапу, щоб не втратити результати роботи.

✓ Правильні назви файлів:
• PR10_Ivanenko.sb3
• PR10_Prizvyshche.sb3
✕ Неправильні назви файлів:

1.3 Користування бібліотеками спрайтів, образів, тла та звуків

Scratch містить вбудовані бібліотеки готових мультимедійних ресурсів, згрупованих за тематичними категоріями (Тварини, Люди, Фантазія, Спорт, Музика тощо). Кожен об'єкт можна не лише обрати з бібліотеки, а й відредагувати у вбудованому графічному або аудіоредакторі, намалювати власноруч, отримати випадковим чином («Сюрприз») чи завантажити з комп'ютера.

1.4 Координатна площина сцени та позиціонування спрайтів

Сцена Scratch має розмір 480 × 360 умовних одиниць (пікселів). Її центр знаходиться в точці (0; 0). Горизонтальна вісь X змінюється від -240 (лівий край) до 240 (правий край), а вертикальна вісь Y — від -180 (нижній край) до 180 (верхній край). Для наочного тренування доречно тимчасово встановлювати бібліотечне тло Xy-grid.

1.5 Основні блоки переміщення за координатами

Блок команди (Scratch 3.0) Призначення Приклад використання
перемістити в x: 0 y: 0
 Миттєво встановлює спрайт у задану точку сцени. Початкова позиція персонажа при старті проєкту.
ковзати 1 сек до x: 120 y: 90
 Плавно переміщує спрайт до вказаних координат за заданий час. Плавний рух героя по маршруту без ривків.
змінити x на 50
 Зсуває спрайт горизонтально праворуч (+) або ліворуч (-). Кроковий рух по прямій лінії.
змінити y на -40
 Зсуває спрайт вертикально вгору (+) або вниз (-). Стрибок вгору або спуск вниз.
💡 Чим відрізняється абсолютне позиціонування від відносного?

Абсолютне позиціонування (перемістити в x: ... y: ..., ковзати ... сек до x: ... y: ...) переносить спрайт у точну адресу на сцені незалежно від того, де він був раніше. Відносне позиціонування (змінити x на ..., змінити y на ...) додає або віднімає вказану кількість кроків від поточних координат спрайта.

≈ 7 хв • до 4 балів

Мета рівня: ознайомитися з інтерфейсом, підготувати робоче середовище, додати ресурси з бібліотек та зберегти базовий файл проєкту.

Крок Дія студента Очікуваний результат
1 Відкрийте середовище Scratch 3.0 та перевірте український інтерфейс (🌐 іконка глобуса → Українська). Усі категорії блоків і меню відображаються українською мовою.
2 Видаліть стандартного спрайта (Рудого Кота) натисканням на значок кошика 🗑️ на панелі спрайтів. Сцена очищена від початкового персонажа.

4 У бібліотеці спрайтів додайте будь-якого персонажа (наприклад, Beetle або Cat Flying) та встановіть Розмір: 70. Спрайт з'явився на сцені у зручному масштабі.

Рівень 3. Творчий — Власна інтерактивна мінісцена
≈ 10 хв • до 3 балів

Створіть власну інтерактивну мінісцену для уроку інформатики в початковій школі (наприклад, «Зустріч друзів у парку» або «Космічна подорож»), продемонструвавши охайну організацію робочого простору та точне позиціонування об'єктів.

✍️ Орієнтовна структура письмового висновку (підказка для студента)
  1. Візуалізація абстрактних чисел: сітка Xy-grid перетворює незрозумілі для молодших школярів числа (включно з від'ємними) на конкретні точки на екрані.
  2. Миттєвий зворотний зв'язок: змінюючи X або Y, учень одразу бачить, куди саме перемістився персонаж (вліво/вправо чи вгору/вниз).
  3. Ігровий контекст: завдання з маршрутами та зустріччю героїв формують просторове мислення природно, без механічного заучування правил.
  4. Пропедевтика математики: робота зі сценою Scratch створює міцну базу для майбутнього вивчення прямокутної системи координат у старших класах.
