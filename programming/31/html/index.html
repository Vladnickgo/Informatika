Комбінування лінійних структур, розгалужень і циклів у VBA-проєкті для обчислення площ складених геометричних фігур

1. Три алгоритмічні структури

Будь-який складний алгоритм будується з трьох базових цеглинок. Розберімо кожну окремо — а потім побачимо, як вони комбінуються в одній програмі.

① Лінійна

Команди виконуються одна за одною, зверху вниз.

② Розгалуження

Вибір одного з двох шляхів залежно від умови.

③ Цикл

Повторення дій, доки умова істинна.

2. Завдання заняття

Створити програму знаходження площі складених фігур, малюнки яких подано нижче. Програма має: реагувати на вибір фігури у списку, приймати числові аргументи, обчислювати результат за відповідною формулою, очищати поля та коректно завершувати роботу.

Фігура 1 — «Сума»

Дві дотичні прямокутні частини
S = a·b + c·d формула для Фігури 1

Фігура 2 — «Різниця»

Великий прямокутник із «вирізаним» отвором
S = a·b − c·d формула для Фігури 2

3. Алгоритм програми

Наша програма — це поєднання всіх трьох структур: лінійні команди (введення / виведення), розгалуження (вибір формули) та циклічна подія (обробка натискань кнопок, доки форма відкрита).

Комбінований алгоритм: лінійні команди + розгалуження + цикл подій

4. Покрокова інструкція

Підготувати малюнки у Paint

Відкрити Paint, встановити потрібні висоту та ширину полотна (наприклад, 600×400 пікселів), намалювати Фігуру 1 і Фігуру 2. Зберегти обидва малюнки у власну папку як fig1.jpg та fig2.jpg.

5. Програмний код

Нижче — повний, виправлений та прокоментований код форми. Зверніть увагу: список заповнюється в UserForm_Initialize (а не в Activate), а вибір малюнка робимо через ListIndex, а не через Text.

5.1. Заповнення списку та вибір малюнка

' Заповнюємо список один раз при створенні форми
Private Sub UserForm_Initialize()
    ComboBox1.Clear
    ComboBox1.AddItem "Фігура 1"
    ComboBox1.AddItem "Фігура 2"
    ComboBox1.ListIndex = 0          ' одразу вибрано першу
End Sub

' Зміна вибору — змінюємо малюнок
Private Sub ComboBox1_Change()
    Dim path As String
    path = ThisWorkbook.path & "\"       ' папка з файлом книги

    Select Case ComboBox1.ListIndex
        Case 0
            Image1.Picture = LoadPicture(path & "fig1.jpg")
        Case 1
            Image1.Picture = LoadPicture(path & "fig2.jpg")
    End Select
End Sub

5.2. Допоміжна функція безпечного перетворення числа

У полях користувач може ввести кому замість крапки або пробіли. Функція Num() робить введення стійким:

Private Function Num(ByVal t As String) As Double
    Num = CDbl(Replace(Replace(t, ",", "."), " ", ""))
End Function

5.3. Обчислення, очищення, вихід

' Кнопка «Обчислити»
Private Sub CommandButton1_Click()
    On Error GoTo errHandler

    Dim a As Double, b As Double
    Dim c As Double, d As Double
    Dim S As Double

    a = Num(TextBox1.Text)
    b = Num(TextBox2.Text)
    c = Num(TextBox3.Text)
    d = Num(TextBox4.Text)

    Select Case ComboBox1.ListIndex
        Case 0
            S = a * b + c * d
        Case 1
            S = a * b - c * d
        Case Else
            MsgBox "Оберіть фігуру!"
            Exit Sub
    End Select

    TextBox5.Text = Format(S, "0.00")
    Exit Sub

errHandler:
    MsgBox "Перевірте правильність числових даних!"
End Sub

' Кнопка «Очистити»
Private Sub CommandButton2_Click()
    TextBox1.Text = ""
    TextBox2.Text = ""
    TextBox3.Text = ""
    TextBox4.Text = ""
    TextBox5.Text = ""
End Sub

' Кнопка «Вихід»
Private Sub CommandButton3_Click()
    Unload Me
End Sub
Чому саме так? Варіант із ComboBox1.Text із оригінального тексту заняття працює, але менш надійний: якщо користувач введе довільний текст, умова не спрацює. Вибір через ListIndex гарантує відповідність «індекс → малюнок → формула».

7. Завдання для самостійного виконання

Скласти програму визначення площі фігури, зображеної на малюнку. Аргументами вважати AB, BC, DE, EK, FG, GH. Побудувати форму, на якій обов'язково має бути зображення фігури, передбачені поля для введення та виведення значень, а також кнопки «Обчислити», «Очистити», «Вихід».

Схема фігури

Фігуру можна розкласти на три дотичні прямокутники, що утворюють «сходинку». Кожен прямокутник має свої розміри — саме їх і задано в умові:

Три дотичні прямокутники; усі шість заданих розмірів видно на малюнку
S = AB·BC + DE·EK + FG·GH загальна формула для цієї фігури
Увага! Формула залежить від конкретної конфігурації фігури у вашій інструкційній картці. Якщо прямокутники перекриваються, потрібно віднімати площу перекриття; якщо утворюють «рамку» — віднімати внутрішній отвір. Принцип той самий: розбити фігуру на прості частини, площі яких обчислюються добутком двох сторін.

Заготовка коду

Option Explicit

Private Function Num(ByVal t As String) As Double
    Num = CDbl(Replace(Replace(t, ",", "."), " ", ""))
End Function

Private Sub CommandButton1_Click()
    On Error GoTo errHandler

    Dim AB As Double, BC As Double
    Dim DE As Double, EK As Double
    Dim FG As Double, GH As Double
    Dim S  As Double

    AB = Num(TextBoxAB.Text)
    BC = Num(TextBoxBC.Text)
    DE = Num(TextBoxDE.Text)
    EK = Num(TextBoxEK.Text)
    FG = Num(TextBoxFG.Text)
    GH = Num(TextBoxGH.Text)

    S = AB * BC + DE * EK + FG * GH

    TextBoxS.Text = Format(S, "0.00")
    Exit Sub

errHandler:
    MsgBox "Перевірте правильність введених даних!"
End Sub

Private Sub CommandButton2_Click()
    TextBoxAB.Text = "": TextBoxBC.Text = ""
    TextBoxDE.Text = "": TextBoxEK.Text = ""
    TextBoxFG.Text = "": TextBoxGH.Text = ""
    TextBoxS.Text  = ""
End Sub

Private Sub CommandButton3_Click()
    Unload Me
End Sub

9. Підсумок

Сьогодні ми об'єднали три базові алгоритмічні структури в одному проєкті VBA:

  • Лінійні команди — введення даних, виведення результату.
  • Розгалуження — Select Case для вибору формули залежно від фігури.
  • Цикл — подієвий цикл форми, який «крутиться», доки користувач не натисне «Вихід».

Такий підхід — декомпозиція складної фігури на прості частини — універсальний: його застосовують і в геометрії, і в інженерних розрахунках, і в програмуванні будь-яких обчислювальних систем.
