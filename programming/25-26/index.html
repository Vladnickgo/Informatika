Питання для обговорення

1. У чому відмінність між повним та неповним розгалуженням?
Повне розгалуження має дві гілки: дії виконуються і при істинній, і при хибній умові (обов'язковий else). Неповне — лише одну гілку: дії виконуються тільки при істинній умові, а при хибній алгоритм просто «обходить» цей блок і йде далі.
2. Наведіть приклад із життя, де використовується повне розгалуження.
«Якщо на вулиці дощ — візьми парасольку, інакше — залиш її вдома». Або: «Якщо оцінка ≥ 12 — похвалити, інакше — дати пораду, як покращити».
3. Наведіть приклад із життя, де використовується неповне розгалуження.
«Якщо на світлофорі червоне світло — зупинись». Якщо зелене — нічого особливого не робимо, просто йдемо далі. Також: «Якщо температура нижче 0 — надінь шапку».
4. Як вибрати, який тип розгалуження краще використати для певної задачі?
Поставте собі запитання: «Чи потрібно виконувати дію і тоді, коли умова хибна?»
  • Якщо так — потрібне повне розгалуження (if…else).
  • Якщо ні — достатньо неповного (if). Зайве else лише ускладнює код.
5. Чому неповне розгалуження називають ще «обхідним»?
Тому що при хибній умові алгоритм «обходить» блок дій — переходить одразу до наступної команди, не виконуючи жодних альтернативних дій. Це як об'їзд перешкоди: коли її немає — просто їдете далі.

Теоретичні відомості

Що таке розгалуження?

Розгалуження — це алгоритмічна структура, яка передбачає вибір однієї з кількох можливих дій залежно від виконання певної умови.

Повне розгалуження

Повне розгалуження — це конструкція, у якій передбачені дії як для випадку, коли умова істинна, так і для випадку, коли вона хибна.

МоваСинтаксис
Javaif (умова) { дія1; } else { дія2; }
Pythonif умова: дія1
else: дія2
VBA (Excel)If умова Then дія1 Else дія2
Scratchякщо <умова> тоді дія1 інакше дія2
Приклад: перевірка парності (Java)
if (число % 2 == 0) {
    System.out.println("Число парне");
} else {
    System.out.println("Число непарне");
}
Приклад із життя: «Якщо на вулиці дощ, то візьми парасольку, інакше — залиш парасольку вдома».

Неповне розгалуження

Неповне розгалуження — це конструкція, у якій дія передбачена тільки для випадку, коли умова істинна. Якщо умова хибна, виконання алгоритму продовжується без додаткових дій (обхід).

МоваСинтаксис
Javaif (умова) { дія1; }
Pythonif умова: дія1
VBA (Excel)If умова Then дія1
Scratchякщо <умова> тоді дія1
Приклад: дія тільки при істинній умові (Java)
if (температура < 0) {
    System.out.println("На вулиці мороз! Одягнись тепліше.");
}
Приклад із життя: «Якщо на світлофорі червоне світло — зупинись».

Завдання 1. Визначення типу розгалуження 8 балів

Визначте, який тип розгалуження (повне чи неповне) використано в наведених прикладах. Заповніть таблицю — клікніть на порожню комірку та введіть відповідь.

№ПрикладТипЧому?
1Якщо на вулиці дощ, то візьми парасольку
2Якщо на вулиці дощ, то візьми парасольку, інакше — залиш вдома
3Якщо оцінка ≥ 12, то «Відмінно», інакше — «Добре»
4Якщо число додатне, то збільшити його на 1

6Якщо температура повітря нижче 0, то надіти шапку

Показати відповіді
  1. Неповне — дія є лише при істинній умові.
  2. Повне — дві дії («взяти» або «залишити»).
  3. Повне — дві альтернативні оцінки.
  4. Неповне — «збільшити» тільки при додатному числі.
  5. Неповне — знижка лише при перевищенні суми.
  6. Неповне — шапка лише при морозі.
  7. Повне — два взаємовиключні варіанти.
  8. Неповне — повідомлення лише для нуля.

Завдання 2. Перетворення між формами 6 балів

2.1. Неповне → повне

Неповне: «Якщо пароль введено правильно, то надати доступ».

Повне: «Якщо пароль введено правильно, то надати доступ, інакше ».

2.2. Повне → неповне

Повне: «Якщо значення > 100, то «Дуже велике», інакше — «Допустиме»».

Неповне: «Якщо значення > 100, то ».

⚠️ Зауважте: ці два розгалуження не еквівалентні. Неповна форма втрачає повідомлення «Допустиме» — програма нічого не скаже, якщо число ≤ 100. Інколи це прийнятно, інколи — ні.

2.3. Текстовий опис → код

Умова: «Якщо вік людини ≥ 18 — вивести «Повнолітній», інакше — «Неповнолітній»».

Java
if (вік >= 18) {
    System.out.println("Повнолітній");
} else {
    System.out.println("Неповнолітній");
}
Python
if вік >= 18:
    print("Повнолітній")
else:
    print("Неповнолітній")
VBA (Excel)
If вік >= 18 Then
    MsgBox "Повнолітній"
Else
    MsgBox "Неповнолітній"
End If

Завдання 5. Аналіз педагогічних ситуацій 8 балів

Для кожної ситуації визначте, який тип розгалуження потрібно використати, та поясніть чому.

№СитуаціяТипПояснення
1 Вчитель перевіряє відповідь учня. Якщо правильно — «+», якщо ні — «−».
2 Вчитель перевіряє, чи є домашнє завдання. Якщо є — ставить оцінку, якщо немає — не ставить.
3 У грі: якщо гравець набрав > 10 очок — переходить на наступний рівень, інакше — залишається.
4 Програма перевіряє пароль. Якщо неправильний — просить ще раз, якщо правильний — надає доступ.
Показати відповіді
  1. Повне — два взаємовиключні результати («+» / «−»), обидва важливі.
  2. Неповне — оцінка ставиться лише за наявності роботи; якщо її немає — просто нічого не робимо.
  3. Повне — дві різні дії: перехід або залишення на рівні.
  4. Неповне (у комбінації з циклом) — повторний запит пароля виконується лише при помилці; при успіху — просто доступ.

Контрольні запитання

1. Що таке повне розгалуження? Наведіть приклад.
Конструкція, у якій дії передбачені і для істинної, і для хибної умови. Приклад: if (x > 0) "додатне"; else "не додатне";.
2. Що таке неповне розгалуження? Наведіть приклад.
Конструкція, у якій дія виконується лише при істинній умові. Приклад: if (дощ) взяти_парасольку; — якщо дощу немає, просто йдемо далі.
3. Як розпізнати повне розгалуження на блок-схемі?
Від ромба (умови) виходять дві стрілки — «Так» і «Ні», і кожна веде до свого блоку дій. Обидві гілки зрештою сходяться перед «Кінець».
4. Як розпізнати неповне розгалуження на блок-схемі?
Від ромба виходить лише одна стрілка з підписом «Так» — до блоку дій. Друга стрілка (без підпису або з «Ні») йде одразу далі, повз блок дій.
5. У яких випадках використовують if-else, а в яких лише if?
  • if-else — коли для обох випадків (істина/хиба) потрібні різні дії.
  • лише if — коли дія потрібна тільки при істинній умові, а при хибній — нічого не робимо.
6. Чи можна замінити повне розгалуження неповним? Якщо так, то як?
Технічно — можна, але з втратою функціональності: гілка else просто зникне, і дія в ній не виконуватиметься. Еквівалентна заміна можлива лише тоді, коли гілка else містить порожній блок (нічого не робить).
7. Чи можна замінити неповне розгалуження повним? Якщо так, то як?
Так — додавши порожній блок else (наприклад, else { /* нічого */ }). Результат той самий, але код стає зайво громіздким. Тому на практиці неповне розгалуження залишають як є.
8. Як вибрати тип розгалуження для конкретної задачі?
Запитайте себе: «Чи потрібна альтернативна дія, якщо умова хибна?» Так → повне; ні → неповне.
9. Що станеться, якщо в повному розгалуженні забути написати else?
Програма перетвориться на неповне розгалуження: при хибній умові жодна дія не виконається, і виконання піде далі. Якщо ця дія була потрібна — це логічна помилка.
10. Наведіть приклад неповного розгалуження в навчальному процесі початкової школи.
«Якщо учень підняв руку — учитель запитує його». Якщо ні — урок іде далі без змін. Або: «Якщо залишився час — встигнемо пограти».
