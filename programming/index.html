Логічні вирази

Оператори If…Then…Else, логічні вирази, блок-схеми.

🎯 Мета заняття

  • Навчитися використовувати оператор розгалуження If.
  • Формувати поняття логічного виразу та його значень.
  • Навчитися тестувати програми на коректність різних умов.
  • Розвивати критичне мислення та вміння прогнозувати сценарії виконання.
  • Виховувати відповідальність за результат: програма має працювати правильно для всіх вхідних даних.
1

Теоретичні відомості

Що таке розгалуження?

Складені команди (структури) дозволяють змінювати порядок виконання програми залежно від певних умов. Найважливіша з них — команда розгалуження.

Розгалуження — це алгоритмічна структура, у якій виконання однієї або іншої послідовності команд залежить від істинності певної умови.

Логічний вираз — це вираз, який набуває одне з двох значень: істина (True) або хиба (False).

Пріоритет операцій

Спочатку виконуються арифметичні дії, потім оператори порівняння, і лише потім — логічні оператори. Для надійності завжди використовуйте дужки:

Пріоритет — приклад
' Без дужок — важко читати й легко помилитись
If a = b And b = c Then ...

' З дужками — однозначно й надійно
If (a = b) And (b = c) Then ...

Синтаксис розгалуження у VBA (Excel)

Повна форма: If … Then … ElseIf … Else … End If

Структура оператора
If умова1 Then
    ' дії, якщо умова1 істинна
ElseIf умова2 Then
    ' дії, якщо умова1 хибна, а умова2 істинна
ElseIf умова3 Then
    ' дії, якщо умова1 та умова2 хибні, а умова3 істинна
Else
    ' дії, якщо всі умови хибні
End If

Скорочена форма (без Else)

If без альтернативи
If x < 0 Then
    MsgBox "Від'ємне число"
End If

Однорядковий If

Якщо в кожній гілці лише одна команда, запис можна скоротити:

Однорядковий запис
If x Mod 2 = 0 Then MsgBox "Парне" Else MsgBox "Непарне"

Багатоваріантний вибір: Select Case

Коли перевіряється багато значень однієї змінної, зручніше використати Select Case:

Select Case
Select Case score
    Case Is >= 90
        MsgBox "Відмінно"
    Case Is >= 75
        MsgBox "Добре"
    Case Is >= 60
        MsgBox "Задовільно"
    Case Else
        MsgBox "Незадовільно"
End Select
Як запустити код в Excel:
  1. Натисніть Alt + F11 — відкриється редактор VBA.
  2. Меню Insert → Module — додайте новий модуль.
  3. Вставте код у вікно модуля.
  4. Натисніть F5 — запуск процедури (або F8 — покроково).

Блок-схеми алгоритмів

Перевірка числа на парність

flowchart TD A([Початок]) --> B[/Ввести число x/] B --> C{"x Mod 2 = 0 ?"} C -->|Так| D[/Вивести «Парне»/] C -->|Ні| E[/Вивести «Непарне»/] D --> F([Кінець]) E --> F

Ромб — умова; прямокутник — дія; паралелограм — введення/виведення

Загальна структура If…ElseIf…Else

flowchart TD A([Початок]) --> B{"Умова 1 ?"} B -->|Так| C[/Блок команд 1/] B -->|Ні| D{"Умова 2 ?"} D -->|Так| E[/Блок команд 2/] D -->|Ні| F[/Блок команд Else/] C --> G([Кінець]) E --> G F --> G

Ланцюжок умов перевіряється згори вниз, доки одна з них не стане істинною

Найбільше з трьох чисел a, b, c

flowchart TD A([Початок]) --> B[/Ввести a, b, c/] B --> C["m ← a"] C --> D{"b > m ?"} D -->|Так| E["m ← b"] D -->|Ні| F{"c > m ?"} E --> F F -->|Так| G["m ← c"] F -->|Ні| H[/Вивести m/] G --> H H --> I([Кінець])

Приклади реалізації на VBA (Excel)

Приклад 1. Парне / непарне число

Найпростіше розгалуження з оператором Mod (остача від ділення).

EvenOdd.bas
Sub EvenOdd()
    Dim x As Long
    x = CLng(InputBox("Введіть ціле число:"))

    If x Mod 2 = 0 Then
        MsgBox "Число парне"
    Else
        MsgBox "Число непарне"
    End If
End Sub

Приклад 2. Визначення типу трикутника ⭐ (основне завдання)

Спочатку перевіряємо умову існування трикутника складеною умовою з And, потім — тип.

TriangleType.bas
Sub TriangleType()
    Dim a As Double, b As Double, c As Double

    a = CDbl(InputBox("Сторона a:"))
    b = CDbl(InputBox("Сторона b:"))
    c = CDbl(InputBox("Сторона c:"))

    ' 1. Перевірка існування трикутника
    If (a + b > c) And (a + c > b) And (b + c > a) Then

        ' 2. Визначення типу
        If (a = b) And (b = c) Then
            MsgBox "Рівносторонній трикутник"
        ElseIf (a = b) Or (a = c) Or (b = c) Then
            MsgBox "Рівнобедрений трикутник"
        Else
            MsgBox "Різносторонній трикутник"
        End If

    Else
        MsgBox "Трикутник з такими сторонами не існує"
    End If
End Sub
Зверніть увагу: перевірку рівності сторін робимо тільки всередині гілки «трикутник існує» — інакше для набору (1, 2, 5) програма могла б помилково видати «Різносторонній».

Приклад 3. Високосний рік

Рік високосний, якщо ділиться на 4, але не на 100, або ділиться на 400.

LeapYear.bas
Function IsLeapYear(y As Integer) As Boolean
    IsLeapYear = ((y Mod 4 = 0) And (y Mod 100 <> 0)) Or (y Mod 400 = 0)
End Function

Sub CheckLeapYear()
    Dim y As Integer
    y = CInt(InputBox("Введіть рік:"))

    If IsLeapYear(y) Then
        MsgBox y & " — високосний рік"
    Else
        MsgBox y & " — не високосний рік"
    End If
End Sub

Приклад 4. Найбільше з трьох чисел

MaxOfThree.bas
Sub MaxOfThree()
    Dim a As Double, b As Double, c As Double, m As Double

    a = CDbl(InputBox("a ="))
    b = CDbl(InputBox("b ="))
    c = CDbl(InputBox("c ="))

    m = a
    If b > m Then m = b
    If c > m Then m = c

    MsgBox "Найбільше число: " & m
End Sub

Приклад 5. Автоматичне тестування таблиці наборів у Excel ⭐

Найзручніший спосіб тестування в Excel: записати тестові набори в комірки A2:C6, а результати отримати в стовпці D.

TestAllTriangles.bas
' Функція повертає результат для однієї трійки сторін
Function TriangleResult(a As Double, b As Double, c As Double) As String
    If (a + b > c) And (a + c > b) And (b + c > a) Then
        If (a = b) And (b = c) Then
            TriangleResult = "Рівносторонній"
        ElseIf (a = b) Or (a = c) Or (b = c) Then
            TriangleResult = "Рівнобедрений"
        Else
            TriangleResult = "Різносторонній"
        End If
    Else
        TriangleResult = "Не трикутник"
    End If
End Function

' Процедура проганяє всі тестові набори зі стовпців A, B, C
Sub TestAllTriangles()
    Dim ws As Worksheet
    Dim i As Long, a As Double, b As Double, c As Double

    Set ws = ActiveSheet
    ws.Range("D1").Value = "Результат"

    For i = 2 To 6
        a = ws.Cells(i, 1).Value
        b = ws.Cells(i, 2).Value
        c = ws.Cells(i, 3).Value
        ws.Cells(i, 4).Value = TriangleResult(a, b, c)
    Next i

    MsgBox "Тестування завершено!"
End Sub
Перевага: один запуск — і ви одразу бачите результати для всіх наборів. Якщо якийсь рядок не збігається з очікуваним — шукайте помилку в умові.

Практичне завдання

Завдання: програма «Визначення типу трикутника»

Напишіть програму, яка за трьома введеними користувачем сторонами a, b, c виконує такі дії:

  1. Перевіряє, чи можуть вони бути сторонами трикутника. Умова існування: сума будь-яких двох сторін повинна бути більшою за третю: a+b>c, a+c>b, b+c>a.
  2. Якщо трикутник існує — визначає його тип:
    • Рівносторонній — усі сторони рівні;
    • Рівнобедрений — дві сторони рівні;
    • Різносторонній — усі сторони різні.
  3. Виводить відповідне повідомлення на екран.
Підказки:
  • Для перевірки існування трикутника використовуйте складену умову з оператором And.
  • Для перевірки рівності сторін — оператор =. Обов'язково беріть умови в дужки.
  • Спочатку перевіряйте існування трикутника, і лише потім — його тип.

Тестування та налагодження

Чому тестування критично важливе?

Програма з розгалуженням має кілька шляхів виконання. Якщо протестувати лише «щасливий» сценарій, помилка в іншій гілці залишиться непоміченою.

  • Перевіряйте кожну гілку (branch coverage).
  • Тестуйте межові значення (0, від'ємні, дуже великі).
  • Перевіряйте некоректні дані (текст замість числа, порожнє введення).

Інструменти налагодження у VBA

  • F8 — покрокове виконання (найкращий інструмент!).
  • F9 — точка зупину (breakpoint) на потрібному рядку.
  • Debug.Print — виведення значень у вікно Immediate (Ctrl+G).
  • Watch — спостереження за змінною під час виконання.
  • Ctrl+Shift+F8 — вихід із покрокового режиму.

Приклад: налагодження через Debug.Print

DebugPrint.bas
Sub DebugTriangle()
    Dim a As Double, b As Double, c As Double
    a = 1: b = 2: c = 5

    ' Виводимо проміжні значення у вікно Immediate (Ctrl+G)
    Debug.Print "a+b-c = " & (a + b - c)
    Debug.Print "a+c-b = " & (a + c - b)
    Debug.Print "b+c-a = " & (b + c - a)

    If (a + b > c) And (a + c > b) And (b + c > a) Then
        Debug.Print "Трикутник існує"
    Else
        Debug.Print "Трикутник НЕ існує"
    End If
End Sub

Контрольні запитання та завдання

Рівень 1 · Базовий
1. Що таке розгалуження в алгоритмі?
Алгоритмічна структура, у якій виконання тієї чи іншої послідовності команд залежить від істинності певної умови.
2. Які ключові слова використовуються для розгалуження у VBA?
If, Then, ElseIf, Else, End If. Для багатоваріантного вибору — Select Case.
3. Яке значення може мати логічний вираз?
Одне з двох: істина (True) або хиба (False).
4. Які оператори порівняння ви знаєте?
У VBA: = (дорівнює), <> (не дорівнює), <, >, <=, >=.
5. Як на блок-схемі позначається умова?
Ромбом. З нього виходять дві стрілки з підписами «Так» і «Ні».
Рівень 2 · Середній
6. Поясніть різницю між If, ElseIf та Else.
  • If — перша умова, яка перевіряється.
  • ElseIf — додаткова умова, що перевіряється, лише якщо всі попередні хибні.
  • Else — гілка, що виконується, коли жодна з умов не є істинною.
7. Наведіть приклад складного логічного виразу з оператором And.
If (a + b > c) And (a + c > b) And (b + c > a) Then — умова існування трикутника.
8. Що станеться, якщо в операторі If не використати відступи?
У VBA відступи не впливають на логіку — блок визначається словами Then … End If. Проте без відступів код стає нечитабельним і його важко налагоджувати. (У Python, навпаки, відступи обов'язкові.)
9. Як перевірити, що число знаходиться в межах від 10 до 20 включно?
If (x >= 10) And (x <= 20) Then …
10. Поясніть, як працює блок-схема для перевірки трикутника.
Спочатку перевіряється складена умова існування трикутника. Якщо вона хибна — виводиться «Не трикутник». Якщо істинна — перевіряється рівність усіх трьох сторін (рівносторонній), потім рівність хоча б двох (рівнобедрений), інакше — різносторонній.
Рівень 3 · Достатній / Високий
11. Напишіть фрагмент коду, який перевіряє, чи є рік високосним.
If ((y Mod 4 = 0) And (y Mod 100 <> 0)) Or (y Mod 400 = 0) Then …
Рік ділиться на 4, але не на 100, або ділиться на 400.
12. Як за допомогою логічних операторів спростити вираз not (x > 5 or y < 10)?
За законами де Моргана: not (A or B) = (not A) and (not B). Отже: (x <= 5) And (y >= 10).
13. Складіть блок-схему для визначення найбільшого з трьох чисел a, b, c.
Див. блок-схему в розділі «Блок-схеми» → «Найбільше з трьох чисел». Ідея: m ← a, далі If b > m Then m = b, потім If c > m Then m = c.
14. У чому важливість тестування програм з розгалуженням?
Програма має кілька шляхів виконання, і кожен треба перевірити. Для задачі про трикутник:
  • (3, 4, 5) — різносторонній;
  • (5, 5, 5) — рівносторонній;
  • (5, 5, 8) — рівнобедрений;
  • (1, 2, 5) — не трикутник;
  • (0, 4, 5) та (−3, 4, 5) — некоректні дані.
15. Як налагоджувати програму, якщо вона дає неправильний результат?
  • Відтворити помилку на конкретних вхідних даних.
  • Поставити точку зупину (F9) і пройти код покроково (F8).
  • Вивести проміжні значення через Debug.Print у вікно Immediate (Ctrl+G).
  • Перевірити кожну умову окремо (можливо, потрібні дужки).
  • Перевірити межові випадки: 0, від'ємні числа, рівні сторони.
