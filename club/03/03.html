Мова CSS: одягаємо сторінку

Минулого разу ми зробили «кістяк» сторінки. Сьогодні додамо до нього колір, шрифти, рамки й відступи — і побачимо, як звичайний текст перетворюється на справжній дизайн.

Що таке CSS?

CSS (Cascading Style Sheets) — каскадні таблиці стилів. Якщо HTML каже браузеру «що це за вміст», то CSS каже «як він має виглядати»: якого кольору, розміру, де розташований, які в нього відступи й рамки.

HTML + CSS

Той самий текст — але з кольором, шрифтом, відступами й заокругленнями.

Це окремий шар

HTML відповідає за зміст, CSS — за вигляд. Їх прийнято тримати окремо, як текст і його оформлення в документі.

Це «каскад»

Кілька правил можуть стосуватись одного елемента. Браузер вибирає «переможця» за чіткими правилами — про це далі.

Це просто

Усередині — лише властивість: значення;. Жодної логіки, циклів чи умов. Ідеально для першого знайомства.

Аналогія: HTML — це кістяк людини, CSS — це одяг, зачіска й макіяж, а JavaScript — це м'язи, які рухають. Минулого разу ми зробили кістяк. Сьогодні одягаємо його.

Три способи підключити стилі

Є три «двері», через які CSS потрапляє на сторінку. Усі три працюють, але призначення в них різне.

1. Вбудований (inline)

Стиль прямо в атрибуті style конкретного тега.

<h1 style="color:#2563eb;">
  Привіт
</h1>

Плюс: швидко перевірити ідею.
Мінус: не працює для великої кількості елементів.

2. Внутрішній

Тег <style> усередині <head> — усі стилі однієї сторінки в одному місці.

<style>
  h1 { color: #2563eb; }
</style>

Плюс: зручно для однієї сторінки.
Мінус: не перевикористати на інших сторінках.

3. Зовнішній

Окремий файл style.css, підключений через <link>.

<link rel="stylesheet"
      href="style.css">

Плюс: один файл — увесь сайт.
Мінус: треба стежити за шляхом до файлу.

Правило хорошого тону: для навчальних експериментів — <style> у <head>, а для справжніх проєктів — окремий файл style.css. Inline-стилі використовують лише для дрібних винятків.

Синтаксис CSS-правила

Уся мова складається з одного візерунка: селектор + фігурні дужки + пари «властивість: значення». Запам'ятайте його — і ви вже знаєте CSS на 70%.

style.css — три правила 
/* Селектор за тегом — усі абзаци на сторінці */
p {
  color: #334155;
  font-size: 16px;
}

/* Селектор за класом — усі елементи з class="card" */
.card {
  background: #ffffff;
  border: 2px solid #dbeafe;
  border-radius: 16px;
  padding: 18px;
}

/* Селектор за id — один-єдиний елемент на сторінці */
#header {
  text-align: center;
  color: #2563eb;
}
Селектор

p, .card, #header — вказує, які саме елементи стилізуємо.

Фігурні дужки { }

Межі правила: усе, що всередині, стосується цього селектора.

Властивість

color, padding — що саме змінюємо в елементі.

Значення

#2563eb, 16px, center — як саме змінюємо.

Крапка з комою ;

Розділяє властивості. Забули — наступна властивість «з'їсть» попередню.

Найчастіша помилка початківців: забути ; після значення або переплутати : і ;. Якщо стиль «не працює» — першим ділом перевіряйте ці два символи.

Селектори: як «впіймати» потрібний елемент

Селектор — це адреса елемента. Три основні типи покривають майже всі потреби початківця.

За тегом

h1 { … } — стилізує усі заголовки першого рівня на сторінці.

Коли: хочемо однаковий вигляд для всіх елементів цього типу.

За класом .назва

.card { … } — стилізує всі елементи з class="card". Клас можна давати багатьом елементам.

Коли: найчастіше! Це основний робочий інструмент.

За id #назва

#header { … } — стилізує єдиний елемент з id="header". Id на сторінці має бути один.

Коли: унікальні блоки — шапка, підвал, головна секція.

як це пов'язано з HTML 
<!-- HTML -->
<div class="card">Картка 1</div>
<div class="card">Картка 2</div>
<div id="header">Шапка сайту</div>

/* CSS — один клас стилізує ОБИДВІ картки */
.card { border: 2px solid #dbeafe; }

Каскад: якщо два правила «сперечаються» за один елемент, перемагає специфічніше: inline-стиль → id → клас → тег. А якщо специфічність однакова — перемагає те правило, що записане нижче у файлі.

Кольори: три способи записати

CSS розуміє колір у кількох форматах. Усі вони рівноцінні — обирайте той, що зручніший.

Назва

color: red; — просто й зрозуміло. Але назв лише близько 140, і точних відтінків серед них немає.

HEX-код

color: #2563eb; — решітка й шість знаків: по два на червоний, зелений, синій. Найпопулярніший формат.

rgb()

color: rgb(37, 99, 235); — три числа від 0 до 255. Зручно, коли треба порахувати відтінок.

Синій#2563eb
Фіолетовий#7c3aed
Малиновий#e11d48
Бурштиновий#f59e0b
Зелений#16a34a
Темно-синій#0d233a

Де брати коди? Найпростіше — у браузері: відкрийте F12, вкладку Elements, і у вкладці Styles клікніть на будь-який квадратик кольору. Відкриється палітра з піпеткою. Або скористайтесь будь-яким «color picker» у пошуку.

Мінімальний набір властивостей

Цих дванадцяти властивостей достатньо, щоб зробити сторінку охайною й приємною. Решту завжди можна знайти в довіднику.

color

Колір тексту. color: #e11d48;

background

Колір або картинка фону. background: #fef3c7;

font-size

Розмір шрифту. font-size: 18px;

font-family

Гарнітура шрифту. font-family: Georgia, serif;

font-weight

Товщина накреслення. font-weight: 700; (= bold)

text-align

Вирівнювання тексту: left, center, right.

padding

Внутрішній відступ — «повітря» між рамкою і вмістом.

margin

Зовнішній відступ — проміжок між елементами.

border

Рамка: border: 2px solid #2563eb;

border-radius

Заокруглення кутів. border-radius: 16px;

width / height

Ширина й висота блоку. width: 300px;

box-shadow

Тінь під блоком. box-shadow: 0 8px 20px rgba(0,0,0,.15);

Порада: не намагайтесь вивчити всі властивості напам'ять — їх понад 300. Достатньо впевнено знати ці дванадцять і вміти гуглити решту (наприклад, на developer.mozilla.org).

Блокова модель: «коробка в коробці»

Кожен елемент у CSS — це прямокутна коробка. Усередині неї — ще три «шари». Розуміти цю схему — означає розуміти, чому відступи працюють саме так.

Головна різниця: padding — це всередині рамки (відсуває текст від країв), а margin — зовні (відсуває блок від сусідів). Якщо здається, що «відступ не там» — майже завжди переплутані саме ці дві властивості.

1Що означає абревіатура CSS?

        
↳ Натисніть, щоб побачити відповідь

        
Cascading Style Sheets — каскадні таблиці стилів.

      

      

        
2За що відповідає CSS, а за що — HTML?

        
↳ Натисніть, щоб побачити відповідь

        
HTML — за зміст і структуру (що це за елемент). CSS — за зовнішній вигляд (колір, шрифт, відступи).

      

      

        
3Як підключити зовнішній файл стилів?

        
↳ Натисніть, щоб побачити відповідь

        
У <head> додати: <link rel="stylesheet" href="style.css">.

      

      

        
4Який селектор вибере елементи з class="card"?

        
↳ Натисніть, щоб побачити відповідь

        
.card — з крапкою на початку. Без крапки це був би селектор за тегом.

      

      

        
5Яка властивість змінює колір тексту?

        
↳ Натисніть, щоб побачити відповідь

        
color. Наприклад: color: #e11d48; (а колір фону — це background).

      

      

        
6Чим відрізняються padding і margin?

        
↳ Натисніть, щоб побачити відповідь

        
padding — відступ всередині (між рамкою і вмістом). margin — зовні (між елементами).

      

      

        
7Що робить border-radius: 16px?

        
↳ Натисніть, щоб побачити відповідь

        
Заокруглює кути елемента радіусом 16 пікселів.

      

      

        
8Що станеться, якщо забути крапку з комою?

        
↳ Натисніть, щоб побачити відповідь

        
Наступна властивість може не застосуватись — браузер «склеїть» два оголошення і відкине обидва.

      

      

        
9Як задати колір фону сторінки?

        
↳ Натисніть, щоб побачити відповідь

        
body { background: #f2f7fd; } — або background-color замість background.

      

      

        
10Що таке inline-стиль і коли він доречний?

        
↳ Натисніть, щоб побачити відповідь

        
Атрибут style="..." прямо в теґу. Доречний для швидких винятків, але не для оформлення цілої сторінки.
