Пояснення на найпростішому прикладі

Уявіть паперову анкету в школі: там є аркуш (сама анкета), підпис («Ваше ім'я»), рядок для запису і дія — віддати вчителю. У HTML форма влаштована точно так само і складається всього з 4 цеглинок!

найпростіша форма (лише 6 рядків!) 
<form>
  <label>Як тебе звати?</label>
  <input type="text" placeholder="Наприклад: Оленка">
  <button type="submit">Привітатися</button>
</form>
👀 Ось як це працює наживо (спробуйте!):

1. <form>…</form> — коробка-контейнер

Як <div>, але розумніший: об'єднує всі поля в одну анкету, щоб браузер знав, які дані надсилати разом при натисканні кнопки.

2. <label>…</label> — підпис поля

Пояснює людині, що саме треба ввести. Без підпису користувач бачить просто порожню рамку і не розуміє, писати туди ім'я чи телефон.

3. <input> — поле для введення

Одинарний тег (як <img>!). Атрибут placeholder показує сіру підказку всередині поля, яка зникає, коли починаєш друкувати.

4. <button>…</button> — кнопка дії

Фінальна кнопка анкети. Атрибут type="submit" каже браузеру: «Усе заповнено, відправляємо форму!».

Зверніть увагу на схожість із минулими уроками: тег <input> — одинарний, як <img> і <br>. А <form> — парний контейнер, як <div>.

Які бувають поля у формах?

Змінюючи всього один атрибут type="..." у тезі <input> (або взявши два додаткові теги), ми можемо збирати будь-яку інформацію.

type="text"

Звичайний однорядковий текст: ім'я, прізвище, місто, клас.

type="email"

Електронна пошта. Браузер сам перевірить, чи є символ @!

type="number"

Лише числа (наприклад, вік учня або номер класу від 1 до 4).

type="checkbox"

Прапорець-галочка: «Погоджуюсь» або вибір кількох гуртків одразу.

type="radio"

Перемикач «тільки один варіант» (наприклад, зміна навчання: 1-ша чи 2-га).

<select> + <option>

Випадаючий список. Працює як <ul> + <li>, тільки компактно ховається!

<textarea>

Велике багаторядкове поле — для відгуку, питання чи твору.

required

Атрибут-охоронець: не дасть відправити форму, поки поле порожнє.

Аналогія зі списками (Заняття 2): пам'ятаєте, що <ul> містить пункти <li>? Точно так само випадаючий список <select> містить варіанти вибору <option>!

Живий результат

Спробуйте в редакторі: додайте перед кнопкою поле для вибору класу: <label>Клас (1–4):</label> та <input type="number" min="1" max="4" placeholder="2">. І зверніть увагу на box-sizing: border-box; — воно не дає полям вилазити за межі картки через padding!

2Чи потрібен закриваючий тег для <input>?
↳ Натисніть, щоб побачити відповідь
Ні! <input> — одинарний тег, так само як <img> або <br>.
3Що робить атрибут placeholder?
↳ Натисніть, щоб побачити відповідь
Показує напівпрозору підказку всередині порожнього поля (приклад заповнення).
4Чим відрізняються <input type="text"> і <textarea>?
↳ Натисніть, щоб побачити відповідь
input — це один рядок (для імені), а textarea — велике багаторядкове поле (для коментаря).
5Який атрибут забороняє відправляти порожнє поле?
↳ Натисніть, щоб побачити відповідь
Атрибут required (обов'язкове поле).
6Як у CSS стилізувати поле в момент, коли користувач у нього клікнув?
↳ Натисніть, щоб побачити відповідь
За допомогою псевдокласу :focus (наприклад, input:focus { border-color: #2563eb; }).
