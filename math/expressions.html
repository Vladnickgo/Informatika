1 Алгебраїчні вирази

Алгебраїчний вираз — це запис, що складається з чисел, змінних, знаків арифметичних дій та дужок. Наприклад: $3x^2 - 2x + 1$, $\dfrac{a+b}{a-b}$, $\sqrt{x+1}$, $\log_2 x$, $2^x$.

Класифікація виразів

  • Цілі — не містять ділення на вираз зі змінною та коренів зі змінної: $5x^3 - 2x$.
  • Дробові — містять змінну в знаменнику: $\dfrac{x}{x-2}$.
  • Ірраціональні — містять змінну під знаком кореня: $\sqrt{x^2+1}$.
  • Показникові — змінна в показнику степеня: $3^{x+1}$.
  • Логарифмічні — змінна під знаком логарифма: $\log_2(x-1)$.
Область допустимих значень (ОДЗ)

Множина всіх значень змінних, за яких вираз має зміст.

• Знаменник ≠ 0: $\dfrac{A}{B}$ — умова $B \neq 0$.

• Підкореневий вираз парного кореня ≥ 0: $\sqrt[2k]{A}$ — умова $A \geq 0$.

• Аргумент логарифма > 0, основа > 0 і ≠ 1: $\log_a B$ — умови $B > 0$, $a > 0$, $a \neq 1$.

• Основа степеня з дробовим показником > 0: $a^{m/n}$ — умова $a > 0$.

Приклад

Знайдіть ОДЗ виразу $\dfrac{\sqrt{x-3}}{x - 5} + \log_2(8 - x)$.

Розв’язання. Маємо три обмеження:

1) $x - 3 \geq 0 \Rightarrow x \geq 3$;

2) $x - 5 \neq 0 \Rightarrow x \neq 5$;

3) $8 - x > 0 \Rightarrow x < 8$.

Перетин: $x \in [3; 5) \cup (5; 8)$.

💡 Порада для НМТ У завданнях на тотожність спочатку визначте тип виразу — від цього залежить, які формули застосовувати. Не починайте перетворення, не побачивши «підказки» в структурі виразу.

2 Многочлени

Одночлен — добуток чисел і змінних у натуральних степенях: $7a^2b^3$.

Многочлен — сума одночленів: $3x^3 - 2x^2 + 5x - 7$.

Степінь многочлена — найбільший зі степенів його членів у стандартному вигляді.

Основні дії з многочленами

Додавання та віднімання

$(A \pm B) \pm C = A \pm B \pm C$ — розкриваємо дужки й зводимо подібні доданки.

Множення

Одночлен на многочлен: $a(b+c) = ab + ac$

Многочлен на многочлен: $(a+b)(c+d) = ac + ad + bc + bd$

Формули скороченого множення (обов’язково знати назубок)

$(a \pm b)^2 = a^2 \pm 2ab + b^2$

$a^2 - b^2 = (a-b)(a+b)$

$(a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$

$a^3 + b^3 = (a+b)(a^2 - ab + b^2)$

$a^3 - b^3 = (a-b)(a^2 + ab + b^2)$

$a^n - b^n = (a-b)(a^{n-1} + a^{n-2}b + \dots + b^{n-1})$

Розкладання квадратного тричлена на множники

Якщо $x_1, x_2$ — корені $ax^2 + bx + c = 0$, то

$$ax^2 + bx + c = a(x - x_1)(x - x_2)$$

Теорема Вієта (для $x^2 + px + q = 0$): $x_1 + x_2 = -p$, $x_1 x_2 = q$.

Методи розкладання на множники

  1. Винесення спільного множника: $6a^2b - 9ab^2 = 3ab(2a - 3b)$.
  2. Групування: $ax + ay + bx + by = (a+b)(x+y)$.
  3. Формули скороченого множення.
  4. Розкладання квадратного тричлена.
  5. Комбінація методів — найчастіший випадок на НМТ.
Приклад 1

Розкладіть на множники: $x^3 - 4x^2 - x + 4$.

Розв’язання. Групуємо: $(x^3 - 4x^2) - (x - 4) = x^2(x - 4) - (x - 4)$.

Виносимо спільний множник $(x-4)$: $(x - 4)(x^2 - 1) = (x - 4)(x-1)(x+1)$.

Приклад 2

Скоротіть: $\dfrac{x^2 - 5x + 6}{x^2 - 9}$.

Розв’язання. Чисельник: $x^2 - 5x + 6 = (x-2)(x-3)$ (корені 2 і 3).

Знаменник: $x^2 - 9 = (x-3)(x+3)$.

$\dfrac{(x-2)(x-3)}{(x-3)(x+3)} = \dfrac{x-2}{x+3}$ при $x \neq 3$, $x \neq -3$.

⚠️ Пастка НМТ При скороченні дробу обов’язково фіксуйте виключені значення змінної. Якщо серед варіантів відповіді є два однакові за виглядом, але різні за ОДЗ — обирайте той, що зберігає початкові обмеження.

3 Раціональні вирази

Раціональний вираз — вираз, що містить лише дії додавання, віднімання, множення, ділення та піднесення до цілого степеня (без коренів і логарифмів зі змінною). Раціональні вирази бувають цілими (многочлени) і дробовими (дробово-раціональні).

Тут розглянемо цілі раціональні вирази — многочлени та їх комбінації. Основна навичка — тотожні перетворення: розкриття дужок, зведення подібних, використання формул.

Ключові тотожності для спрощення

$(a+b)^2 + (a-b)^2 = 2(a^2 + b^2)$

$(a+b)^2 - (a-b)^2 = 4ab$

$a^2 + b^2 = (a+b)^2 - 2ab = (a-b)^2 + 2ab$

$a^3 + b^3 = (a+b)^3 - 3ab(a+b)$

Приклад 1

Спростіть: $(a+b)^2 - (a-b)^2 + (a+b)(a-b)$.

Розв’язання. Розкриваємо кожну дужку:

$(a^2 + 2ab + b^2) - (a^2 - 2ab + b^2) + (a^2 - b^2)$

$= a^2 + 2ab + b^2 - a^2 + 2ab - b^2 + a^2 - b^2 = a^2 + 4ab - b^2$.

Приклад 2

Відомо, що $a + b = 7$, $ab = 10$. Знайдіть $a^2 + b^2$.

Розв’язання. Використовуємо тотожність:

$a^2 + b^2 = (a+b)^2 - 2ab = 49 - 20 = 29$.

Приклад 3 · Доведення тотожності

Доведіть, що $(a^2 + b^2)(c^2 + d^2) = (ac - bd)^2 + (ad + bc)^2$.

Розв’язання. Розкриємо праву частину:

$(a^2c^2 - 2abcd + b^2d^2) + (a^2d^2 + 2abcd + b^2c^2)$

$= a^2c^2 + b^2d^2 + a^2d^2 + b^2c^2$.

Ліва частина: $a^2c^2 + a^2d^2 + b^2c^2 + b^2d^2$. Отримали те саме — тотожність доведено.

💡 Порада для НМТ У завданнях «знайти значення виразу, якщо відомо…» майже завжди потрібно виразити шукане через суму та добуток змінних, а не розв’язувати систему.

4 Дробово-раціональні вирази

Дробово-раціональний вираз — відношення двох многочленів: $\dfrac{P(x)}{Q(x)}$, де $Q(x) \neq 0$.

Основна властивість дробу

$\dfrac{A}{B} = \dfrac{A \cdot C}{B \cdot C}$ при $B \neq 0$, $C \neq 0$.

Дії з дробами:

$\dfrac{a}{c} \pm \dfrac{b}{c} = \dfrac{a \pm b}{c}$;   $\dfrac{a}{b} \cdot \dfrac{c}{d} = \dfrac{ac}{bd}$;   $\dfrac{a}{b} : \dfrac{c}{d} = \dfrac{a}{b} \cdot \dfrac{d}{c} = \dfrac{ad}{bc}$

Алгоритм спрощення дробово-раціонального виразу

  1. Визначити ОДЗ (усі знаменники ≠ 0).
  2. Розкласти чисельники та знаменники на множники.
  3. Звести до спільного знаменника (при додаванні/відніманні).
  4. Скоротити спільні множники.
  5. Записати відповідь із зазначенням обмежень.
Приклад 1 · Додавання

Спростіть: $\dfrac{m^2 + 5m}{m^2 - 3m} + \dfrac{7}{m^2 - 3m} - \dfrac{11m - 2}{m^2 - 3m}$.

Розв’язання. Знаменники однакові — об’єднуємо чисельники:

$\dfrac{m^2 + 5m + 7 - (11m - 2)}{m^2 - 3m} = \dfrac{m^2 - 6m + 9}{m^2 - 3m}$.

Розкладаємо: $\dfrac{(m-3)^2}{m(m-3)} = \dfrac{m-3}{m}$ при $m \neq 0$, $m \neq 3$.

Приклад 2 · Множення

Спростіть: $\dfrac{x^2 - 4}{x^2 + 4x + 4} \cdot \dfrac{x+2}{x-2}$.

Розв’язання. Розкладаємо чисельник першого дробу та знаменник:

$x^2 - 4 = (x-2)(x+2)$;   $x^2 + 4x + 4 = (x+2)^2$.

$\dfrac{(x-2)(x+2)}{(x+2)^2} \cdot \dfrac{x+2}{x-2} = \dfrac{(x-2)(x+2)(x+2)}{(x+2)^2(x-2)} = 1$.

при $x \neq \pm 2$.

Приклад 3 · «Багатоповерховий» дріб

Спростіть: $\dfrac{1 + \dfrac{1}{x}}{1 - \dfrac{1}{x^2}}$.

Розв’язання. Зводимо чисельник і знаменник:

Чисельник: $1 + \dfrac{1}{x} = \dfrac{x+1}{x}$. Знаменник: $1 - \dfrac{1}{x^2} = \dfrac{x^2-1}{x^2} = \dfrac{(x-1)(x+1)}{x^2}$.

Ділення: $\dfrac{(x+1)/x}{(x-1)(x+1)/x^2} = \dfrac{x+1}{x} \cdot \dfrac{x^2}{(x-1)(x+1)} = \dfrac{x}{x-1}$.

при $x \neq 0, \pm 1$.

⚠️ Пастка НМТ Не можна скорочувати доданки! $\dfrac{x+3}{x+5} \neq \dfrac{3}{5}$ — «скорочувати» можна тільки множники, а не доданки чисельника й знаменника. Це найпоширеніша помилка.

5 Показникові вирази

Показниковий вираз містить змінну в показнику степеня: $3^{2x-1}$, $a^{x+1}$, $e^{-x}$.

Властивості степенів ($a > 0$, $b > 0$)

$a^x \cdot a^y = a^{x+y}$;   $\dfrac{a^x}{a^y} = a^{x-y}$;   $(a^x)^y = a^{xy}$

$(ab)^x = a^x b^x$;   $\left(\dfrac{a}{b}\right)^x = \dfrac{a^x}{b^x}$

$a^0 = 1$ ($a \neq 0$);   $a^{-x} = \dfrac{1}{a^x}$

$a^{m/n} = \sqrt[n]{a^m}$   (для $a > 0$)

Приклад 1 · Зведення до однієї основи

Спростіть: $\dfrac{2^{x+3} \cdot 4^{x-1}}{8^{x-2}}$.

Розв’язання. Зводимо всі основи до 2:

$4^{x-1} = 2^{2(x-1)} = 2^{2x-2}$;   $8^{x-2} = 2^{3(x-2)} = 2^{3x-6}$.

$\dfrac{2^{x+3} \cdot 2^{2x-2}}{2^{3x-6}} = 2^{(x+3)+(2x-2)-(3x-6)} = 2^{7} = 128$.

Приклад 2 · Раціональний показник

Подайте у вигляді степеня: $\sqrt[3]{a^2} \cdot \sqrt{a}$ ($a > 0$).

Розв’язання. $\sqrt[3]{a^2} = a^{2/3}$, $\sqrt{a} = a^{1/2}$.

$a^{2/3} \cdot a^{1/2} = a^{2/3 + 1/2} = a^{7/6}$.

Приклад 3 · «Винесення спільного»

Спростіть: $\dfrac{3^{n+1} + 3^{n-1}}{3^{n-1}}$.

Розв’язання. У чисельнику виносимо $3^{n-1}$:

$3^{n+1} + 3^{n-1} = 3^{n-1}(3^2 + 1) = 10 \cdot 3^{n-1}$.

Тоді $\dfrac{10 \cdot 3^{n-1}}{3^{n-1}} = 10$.

⚠️ Пастка НМТ $(-8)^{1/3} = -2$ має зміст, але $(-8)^{2/6}$ — уже ні (бо це парний корінь з від’ємного). Якщо бачите степінь із раціональним показником — перевіряйте умову $a > 0$ або парність/непарність знаменника.

6 Логарифмічні вирази

Означення: $\log_a b = c \iff a^c = b$, де $a > 0$, $a \neq 1$, $b > 0$.

Властивості логарифмів

$\log_a (bc) = \log_a b + \log_a c$

$\log_a \dfrac{b}{c} = \log_a b - \log_a c$

$\log_a b^n = n \log_a b$

$\log_{a^n} b = \dfrac{1}{n} \log_a b$

$a^{\log_a b} = b$;   $\log_a a = 1$;   $\log_a 1 = 0$

Перехід до нової основи: $\log_a b = \dfrac{\log_c b}{\log_c a}$;   $\log_a b = \dfrac{1}{\log_b a}$

Приклад 1 · Спрощення

Спростіть: $\log_5 25x^2 - 2\log_5 x$ ($x > 0$).

Розв’язання. $\log_5 25x^2 = \log_5 25 + \log_5 x^2 = 2 + 2\log_5 x$.

Тоді $2 + 2\log_5 x - 2\log_5 x = 2$.

Приклад 2 · Потенціювання

Знайдіть $x$, якщо $\lg x = 5\lg c - \dfrac{1}{3}\lg a$.

Розв’язання. За властивостями логарифмів:

$\lg x = \lg c^5 - \lg a^{1/3} = \lg \dfrac{c^5}{\sqrt[3]{a}}$.

Отже, $x = \dfrac{c^5}{\sqrt[3]{a}}$ (за умови $c > 0$, $a > 0$).

Приклад 3 · Перехід до нової основи

Обчисліть $\log_4 8 \cdot \log_8 16$.

Розв’язання. Переходимо до основи 2:

$\log_4 8 = \dfrac{\log_2 8}{\log_2 4} = \dfrac{3}{2}$;   $\log_8 16 = \dfrac{\log_2 16}{\log_2 8} = \dfrac{4}{3}$.

Добуток: $\dfrac{3}{2} \cdot \dfrac{4}{3} = 2$.

⚠️ Пастка НМТ Формула $\log_a b^n = n\log_a b$ беззастережно працює лише за $b > 0$. Якщо $b$ може бути від’ємним, правильний запис: $\log_a b^2 = 2\log_a |b|$. У тестах часто пропонують саме «уточнений» варіант як правильний.

7 Ірраціональні вирази

Ірраціональний вираз містить змінну під знаком кореня (радикала): $\sqrt{x+1}$, $\sqrt[3]{x^2-1}$.

Властивості арифметичного кореня

$\sqrt[n]{a^n} = |a|$ для парного $n$;   $\sqrt[n]{a^n} = a$ для непарного $n$

$\sqrt[n]{ab} = \sqrt[n]{a} \cdot \sqrt[n]{b}$;   $\sqrt[n]{\dfrac{a}{b}} = \dfrac{\sqrt[n]{a}}{\sqrt[n]{b}}$ ($b \neq 0$)

$\sqrt[n]{a^m} = a^{m/n}$ (для $a \geq 0$, парного $n$)

$\left(\sqrt[n]{a}\right)^n = a$;   $\sqrt[n]{\sqrt[m]{a}} = \sqrt[nm]{a}$

Позбавлення від ірраціональності в знаменнику

$\dfrac{1}{\sqrt{a}} = \dfrac{\sqrt{a}}{a}$

$\dfrac{1}{\sqrt{a} \pm \sqrt{b}} = \dfrac{\sqrt{a} \mp \sqrt{b}}{a - b}$

$\dfrac{1}{\sqrt[3]{a} \pm \sqrt[3]{b}} = \dfrac{\sqrt[3]{a^2} \mp \sqrt[3]{ab} + \sqrt[3]{b^2}}{a \pm b}$

Приклад 1 · Спрощення кореня

Спростіть: $\sqrt{(a^2 - 4)^2 + 16a^2}$.

Розв’язання. Розкриваємо внутрішній квадрат:

$(a^2 - 4)^2 + 16a^2 = a^4 - 8a^2 + 16 + 16a^2 = a^4 + 8a^2 + 16$.

Помічаємо повний квадрат: $a^4 + 8a^2 + 16 = (a^2 + 4)^2$.

Отже, $\sqrt{(a^2 + 4)^2} = |a^2 + 4| = a^2 + 4$ (бо $a^2 + 4 > 0$).

Приклад 2 · Позбавлення ірраціональності

Звільніться від ірраціональності: $\dfrac{1}{\sqrt{2} + \sqrt{3} + 1}$.

Розв’язання. Групуємо: $(\sqrt{2} + 1) + \sqrt{3}$. Множимо на спряжений $(\sqrt{2} + 1) - \sqrt{3}$:

$\dfrac{\sqrt{2} + 1 - \sqrt{3}}{(\sqrt{2}+1)^2 - 3} = \dfrac{\sqrt{2} + 1 - \sqrt{3}}{3 + 2\sqrt{2} - 3} = \dfrac{\sqrt{2} + 1 - \sqrt{3}}{2\sqrt{2}}$.

Домножуємо на $\sqrt{2}$:

$\dfrac{(\sqrt{2} + 1 - \sqrt{3})\sqrt{2}}{2\sqrt{2}\cdot\sqrt{2}} = \dfrac{2 + \sqrt{2} - \sqrt{6}}{4}$.

Приклад 3 · Формула «різниця квадратів»

Обчисліть: $(\sqrt{5} - \sqrt{3})(\sqrt{5} + \sqrt{3})$.

Розв’язання. За формулою $a^2 - b^2$:

$(\sqrt{5})^2 - (\sqrt{3})^2 = 5 - 3 = 2$.

⚠️ Пастка НМТ $\sqrt{x^2} = |x|$, а не $x$. Якщо серед варіантів є «$x$» без модуля — він майже завжди хибний, якщо в умові не вказано $x \geq 0$. Також: $\sqrt{a} + \sqrt{b} \neq \sqrt{a+b}$ — додавати корені «під один корінь» не можна.

Алгебраїчний (загально) Числа, змінні, дії, дужки Класифікація, ОДЗ
Многочлен Сума одночленів Формули скороченого множення, групування, Вієт

Ірраціональний Змінна під коренем Властивості коренів, спряжений вираз, $|x|$

Ситуація Правильно Неправильно (пастка)
Корінь парного степеня $\sqrt{x^2} = |x|$ $\sqrt{x^2} = x$
Логарифм квадрата $\log_a x^2 = 2\log_a |x|$ $\log_a x^2 = 2\log_a x$ без умови $x>0$
Скорочення дробу Скорочувати лише множники + врахувати ОДЗ Скорочувати доданки: $\dfrac{x+3}{x+5} = \dfrac{3}{5}$

🎯 Стратегія на НМТ
  1. Класифікуйте вираз — до якого типу він належить?
  2. Згадайте 1–2 ключові формули саме для цього типу.
  3. Перевірте ОДЗ до початку перетворень.
  4. Розбийте на кроки — не намагайтеся «розв’язати все одразу».
  5. Підставте число з варіантів відповіді для перевірки, якщо є сумніви.
