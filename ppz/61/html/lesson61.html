1. Теоретичні відомості

1.1. Способи запуску макросів

Макрос можна запустити шістьма способами (схема 1). Вибір способу залежить від того, хто ним користуватиметься: розробник під час налагодження натискає F5 у редакторі VBA, а кінцевий користувач — кнопку на аркуші або сполучення клавіш. Для програм із повторюваним використанням зручно закріпити макрос на панелі швидкого доступу або запускати його автоматично через подію Excel.

Порада

Для налагодження найзручніше використовувати F5 у редакторі VBA та покрокове виконання F8. Для кінцевого користувача — кнопка на аркуші або головне меню.

1.2. Функція MsgBox

MsgBox — функція для виведення діалогового вікна з повідомленням. Вона має три основні параметри: промпт (обов'язковий текст повідомлення), кнопки (тип кнопок та іконки) і заголовок (назва вікна). Функція повертає код натиснутої користувачем кнопки, тому MsgBox часто використовують не лише для інформування, а й для отримання відповіді (схема 2).

Приклад використання MsgBox

Розглянемо діалог із запитом підтвердження та різними реакціями на відповідь користувача.

VBA
Sub ПрикладMsgBox()
    Dim відповідь As Integer
    відповідь = MsgBox("Зберегти зміни?", _
                       vbYesNoCancel + vbQuestion, _
                       "Підтвердження")
    Select Case відповідь
        Case vbYes
            MsgBox "Зміни збережено.", vbInformation
        Case vbNo
            MsgBox "Зміни скасовано.", vbExclamation
        Case vbCancel
            MsgBox "Вихід без збереження.", vbCritical
    End Select
End Sub

1.3. Функція InputBox

InputBox — функція для введення даних через діалогове вікно. Вона має промпт (запит до користувача), заголовок вікна та значення за замовчуванням (те, що вже стоїть у полі введення). Функція повертає рядок — введений користувачем текст або порожній рядок, якщо вікно закрито кнопкою «Скасувати» (схема 3).

Найважливіша перевірка після виклику InputBox

Порівняння результату з порожнім рядком. Якщо користувач натиснув «Скасувати», подальша робота програми втрачає сенс, тому виконують достроковий вихід із процедури: If текст = "" Then Exit Sub.

Значення, яке повертає InputBox, має тип String. Перш ніж використовувати його як число (наприклад, оцінку), перевірте, чи можна його перетворити: якщо користувач ввів літери замість цифр, подальші обчислення дадуть помилку.

Приклад використання InputBox

VBA
Sub ПрикладInputBox()
    Dim вік As String
    вік = InputBox("Введіть ваш вік:", "Вік", "18")
    If вік = "" Then Exit Sub
    If Not IsNumeric(вік) Then
        MsgBox "Вік має бути числом!", vbCritical
        Exit Sub
    End If
    MsgBox "Ваш вік: " & вік, vbInformation
End Sub

1.4. Комбінування MsgBox та InputBox

У реальній програмі ці дві функції працюють разом: InputBox збирає дані, перевірки відсіюють некоректні значення, а MsgBox повідомляє результат і запитує підтвердження перед незворотною дією (схема 5). Такий ланцюжок забезпечує зрозумілий діалог із користувачем.

VBA — приклад комбінування
Sub Знайомство()
    Dim імʼя As String
    імʼя = InputBox("Як вас звати?", "Знайомство")
    If імʼя = "" Then Exit Sub
    MsgBox "Привіт, " & імʼя & "!", vbInformation, "Вітання"
End Sub

1.5. Автоматичний запуск через подію Workbook_Open

Окремий спосіб запуску — прив'язка макросу до події. Процедура з ім'ям Workbook_Open автоматично виконується під час відкриття книги. Вона розміщується не в модулі, а в об'єкті ThisWorkbook у редакторі VBA. Такий прийом зручний для вітального повідомлення або автоматичного оновлення даних.

VBA — ThisWorkbook
Private Sub Workbook_Open()
    MsgBox "Вітаємо у програмі обліку оцінок!" & vbCrLf & _
           "Для роботи натисніть кнопку «Головне меню»", _
           vbInformation
End Sub

2. Покроковий алгоритм виконання різнорівневих завдань

Практична частина складається з трьох рівнів. Рівень 1 — відпрацювання базових функцій, рівень 2 — об'єднання введення й перевірки, рівень 3 — створення повноцінної інтерактивної програми з меню.

Рівень 1. Репродуктивний

Завдання. Створити два простих макроси: вітальне повідомлення та запит оцінки з перевіркою на скасування.

Макрос 1.1. Привітання

Виводить MsgBox із заголовком «Вітання» та іконкою vbInformation.

VBA
Sub Привітання()
    MsgBox "Ласкаво просимо до програми обліку оцінок!", _
           vbInformation, "Вітання"
End Sub

Макрос 1.2. ВвестиОцінку

Запитує оцінку через InputBox зі значенням за замовчуванням 10 і повідомляє про скасування, якщо користувач закрив вікно.

VBA
Sub ВвестиОцінку()
    Dim оцінка As String
    оцінка = InputBox("Введіть оцінку (1-12):", _
                      "Оцінювання", 10)

    If оцінка = "" Then
        MsgBox "Операцію скасовано!", _
               vbExclamation, "Скасування"
        Exit Sub
    End If

    MsgBox "Ви ввели: " & оцінка, vbInformation, "Результат"
End Sub

Рівень 2. Продуктивний

Завдання. Створити макрос ДодатиУчня, який послідовно запитує прізвище та оцінку, перевіряє коректність уведених даних, запитує підтвердження через MsgBox vbYesNo і лише після цього записує рядок у таблицю.

Орієнтовний каркас коду

VBA — ДодатиУчня
Sub ДодатиУчня()
    Dim прізвище As String
    Dim оцінка As Variant
    Dim рядок As Long
    Dim відповідь As Integer

    прізвище = InputBox("Введіть прізвище учня:", "Новий учень")
    If прізвище = "" Then
        MsgBox "Операцію скасовано!", vbExclamation
        Exit Sub
    End If

    оцінка = InputBox("Введіть оцінку (1-12):", _
                      "Новий учень", 10)
    If оцінка = "" Then Exit Sub

    If Not IsNumeric(оцінка) Then
        MsgBox "Оцінка має бути числом!", vbCritical
        Exit Sub
    End If
    If оцінка < 1 Or оцінка > 12 Then
        MsgBox "Оцінка має бути від 1 до 12!", vbCritical
        Exit Sub
    End If

    відповідь = MsgBox("Прізвище: " & прізвище & vbCrLf & _
                       "Оцінка: " & оцінка & vbCrLf & _
                       "Додати запис?", _
                       vbYesNo + vbQuestion, "Перевірка")
    If відповідь <> vbYes Then Exit Sub

    рядок = Cells(Rows.Count, 2).End(xlUp).Row + 1
    Cells(рядок, 1).Value = рядок - 1
    Cells(рядок, 2).Value = прізвище
    Cells(рядок, 3).Value = оцінка
    MsgBox "Учня " & прізвище & " додано!", vbInformation
End Sub

Чому важлива IsNumeric?

Функція IsNumeric повертає True, якщо значення можна перетворити на число. Без цієї перевірки введення літер під час порівняння оцінка < 1 спричинить помилку виконання та зупинку макросу.

Рівень 3. Творчий

Завдання. Побудувати повноцінну інтерактивну програму обліку оцінок із меню, видаленням записів, пошуком і вітальним повідомленням під час відкриття книги.

Склад програми

  1. Головне меню — MsgBox vbYesNoCancel; «Так» → додати учня, «Ні» → видалити, «Скасувати» → вихід.
  2. Видалення учня — перевірка активної комірки, MsgBox vbYesNo для підтвердження, видалення рядка та перенумерація.
  3. Пошук учня — InputBox для прізвища, цикл по таблиці, MsgBox із результатом.
  4. Подія Workbook_Open — вітальне повідомлення під час відкриття книги (розміщується в об'єкті ThisWorkbook).
  5. Кнопка на аркуші — прив'язати до макросу «ГоловнеМеню».

Макрос ГоловнеМеню

VBA
Sub ГоловнеМеню()
    Dim вибір As Integer
    Do
        вибір = MsgBox("Виберіть дію:" & vbCrLf & _
                       "Так — Додати учня" & vbCrLf & _
                       "Ні — Видалити учня" & vbCrLf & _
                       "Скасувати — Вихід", _
                       vbYesNoCancel + vbInformation, _
                       "Головне меню")
        Select Case вибір
            Case vbYes: Call ДодатиУчня
            Case vbNo:  Call ВидалитиУчня
            Case vbCancel
                MsgBox "До побачення!", vbInformation
                Exit Sub
        End Select
    Loop
End Sub

Макрос ВидалитиУчня

VBA
Sub ВидалитиУчня()
    Dim р As Long, і As Long
    Dim прізвище As String
    р = ActiveCell.Row
    If р < 2 Or Cells(р, 2).Value = "" Then
        MsgBox "Виділіть рядок учня!", vbExclamation
        Exit Sub
    End If
    прізвище = Cells(р, 2).Value
    If MsgBox("Видалити " & прізвище & "?", _
              vbYesNo + vbQuestion) <> vbYes Then Exit Sub
    Rows(р).Delete Shift:=xlUp
    For і = 2 To Cells(Rows.Count, 2).End(xlUp).Row
        Cells(і, 1).Value = і - 1
    Next і
    MsgBox "Учня " & прізвище & " видалено!", vbInformation
End Sub

Макрос ПошукУчня

VBA
Sub ПошукУчня()
    Dim пошук As String, і As Long
    пошук = InputBox("Прізвище для пошуку:", "Пошук")
    If пошук = "" Then Exit Sub
    For і = 2 To Cells(Rows.Count, 2).End(xlUp).Row
        If LCase(Cells(і, 2)) Like LCase("*" & пошук & "*") Then
            Cells(і, 2).Select
            MsgBox "Знайдено: " & Cells(і, 2) & _
                   vbCrLf & "Оцінка: " & Cells(і, 3), _
                   vbInformation
            Exit Sub
        End If
    Next і
    MsgBox "Учня не знайдено!", vbExclamation
End Sub

4. Форма звітності

За результатами заняття студент подає два файли:

  1. Книгу Excel — Прізвище_ПЗ17_діалоги.xlsm з усіма макросами та кнопкою на аркуші;
  2. Звіт — ПЗ17_Прізвище.docx, оформлений у текстовому редакторі Word (Times New Roman, 14 pt, інтервал 1,15).

Структура звіту

  1. тема та мета роботи;
  2. коротке пояснення ролі MsgBox та InputBox (3–5 речень);
  3. код кожної процедури з коментарями;
  4. скріншоти вікон MsgBox та InputBox для кожного рівня (не менше ніж 5);
  5. опис виявлених труднощів та способів їх подолання;
  6. висновки (4–6 речень): де в роботі вчителя початкової школи доречно застосовувати інтерактивні діалоги.
💡 Підказка до висновків

Інтерактивні діалоги MsgBox та InputBox доречно використовувати для: вітального повідомлення під час відкриття журналу; запиту оцінки чи прізвища учня; підтвердження видалення запису; повідомлення про помилку введення; організації простого меню для вчителя. Це робить роботу з електронним журналом зрозумілішою та безпечнішою.
