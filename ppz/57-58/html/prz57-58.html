Теоретичні відомості

1. Поняття циклу

Цикл — це конструкція алгоритму, яка дозволяє багаторазово виконувати одну й ту саму послідовність команд. Замість того, щоб десять разів писати один і той самий рядок коду для десяти учнів, ми пишемо його один раз і «прокручуємо» у циклі.

1

Менше коду

Одна й та сама дія описується один раз, а не N разів.

2

Менше помилок

Копіювання рядків вручну майже завжди призводить до друкарських помилок.

3

Масштабованість

10 учнів чи 1000 — код залишається тим самим, змінюється лише межа циклу.

Основні типи циклів у VBA

Тип циклу Опис Коли використовувати
For…Next Цикл із лічильником Коли відома кількість повторень
For Each…Next Цикл по колекції об'єктів Для перебору всіх елементів (клітинки, аркуші)
Do While…Loop Цикл з передумовою Кількість повторень невідома, умова перевіряється на початку
Do Until…Loop Цикл з передумовою (до досягнення умови) Виконується, поки умова хибна
Do…Loop While Цикл з післяумовою Виконується хоча б один раз

Теорія · Цикл 1

2. Цикл For…Next

Цикл із лічильником. Використовується, коли наперед відома кількість повторень.

Синтаксис

For лічильник = початок To кінець [Step крок]
    ' Тіло циклу (команди, що повторюються)
Next [лічильник]

Приклад 1. Простий цикл від 1 до 10

' Простий цикл від 1 до 10
For i = 1 To 10
    Cells(i, 1).Value = i
Next i

Приклад 2. Цикл з кроком 2 (парні числа)

' Цикл з кроком 2 (парні числа)
For i = 2 To 20 Step 2
    Cells(i, 1).Value = i
Next i

Приклад 3. Цикл у зворотному напрямку

' Цикл у зворотному напрямку
For i = 10 To 1 Step -1
    Cells(i, 1).Value = i
Next i
Зверніть увагу

Якщо Step не вказано, за замовчуванням він дорівнює 1. Для зворотного напрямку обов'язково вказуйте від'ємний крок (Step -1), інакше цикл не виконається жодного разу.

Теорія · Цикл 2

3. Цикл Do While…Loop

Цикл із передумовою: тіло виконується доти, поки умова істинна. Кількість повторень заздалегідь невідома.

Синтаксис

Do While умова
    ' Тіло циклу (виконується, поки умова істинна)
Loop

Приклад 1. Цикл, поки клітинка не порожня

' Цикл, поки клітинка не порожня
i = 1
Do While Cells(i, 1).Value <> ""
    i = i + 1
Loop

Приклад 2. Накопичення суми

' Цикл із заданою умовою
сума = 0
i = 1
Do While i <= 10
    сума = сума + i
    i = i + 1
Loop

Теорія · Цикл 3

4. Цикл Do Until…Loop

Цикл із передумовою «до досягнення»: тіло виконується, поки умова хибна. Щойно умова стає істинною — цикл завершується.

Синтаксис

Do Until умова
    ' Тіло циклу (виконується, поки умова хибна)
Loop

Приклад

i = 1
Do Until i > 10
    Cells(i, 1).Value = i
    i = i + 1
Loop
Do While чи Do Until?

Do While i <= 10 та Do Until i > 10 — логічно еквівалентні. Обирайте ту форму, яка природніше читається у контексті задачі: «працюємо, поки є дані» — While, «працюємо, доки не знайдемо» — Until.

Теорія · Цикл 4

5. Цикл For Each…Next

Спеціальний цикл для перебору колекцій об'єктів: клітинок діапазону, аркушів книги, фігур тощо. Не потребує лічильника.

Синтаксис

For Each елемент In колекція
    ' Дії з елементом
Next елемент

Приклад 1. Перебір усіх клітинок виділеного діапазону

' Перебір усіх клітинок виділеного діапазону
For Each cell In Selection
    If cell.Value > 10 Then
        cell.Interior.Color = vbGreen
    End If
Next cell

Приклад 2. Перебір усіх аркушів книги

' Перебір усіх аркушів книги
For Each ws In Worksheets
    MsgBox ws.Name
Next ws
Перевага

Цикл For Each…Next не залежить від кількості елементів: додали новий аркуш або розширили виділений діапазон — код працює без змін.

Теорія · Практика вибору

Теорія · Типові помилки

7. Уникнення нескінченних циклів

Нескінченний цикл — це цикл, умова якого ніколи не стає хибною. Програма «зависає», Excel перестає реагувати на команди.

Як уникнути

  • Завжди змінюйте змінну умови в тілі циклу.
  • Перевіряйте межі циклу For (початкове та кінцеве значення лічильника).
  • Використовуйте «запобіжник» для Do While — додатковий лічильник або перевірку If i > 1000 Then Exit Do.

Приклад нескінченного циклу (помилка)

' НЕПРАВИЛЬНО – нескінченний цикл
i = 1
Do While i <= 10
    Cells(i, 1).Value = i
    ' Забули збільшити i!
Loop

Правильний варіант

i = 1
Do While i <= 10
    Cells(i, 1).Value = i
    i = i + 1   ' Збільшуємо лічильник — обов'язково!
Loop
⚠️ Небезпека на практиці

Якщо Excel все ж «завис» — натисніть Ctrl + Break (або Esc), щоб перервати виконання макросу. У крайньому разі закрийте Excel через «Диспетчер завдань».

Теорія · Керування циклом

8. Exit For та Exit Do

Призначення — достроковий вихід із циклу при виконанні певної умови. Це економить час: далі шукати вже не потрібно.

Вихід із циклу For

' Вихід із циклу For при знаходженні першого значення > 10
For i = 1 To 100
    If Cells(i, 1).Value > 10 Then
        MsgBox "Знайдено значення: " & Cells(i, 1).Value
        Exit For
    End If
Next i

Вихід із циклу Do While

' Вихід із циклу Do While
Do While True
    значення = InputBox("Введіть число (0 для виходу)")
    If значення = 0 Then Exit Do
    Cells(i, 1).Value = значення
    i = i + 1
Loop
Порада

Комбінація «цикл + Exit» — це фактично пошук. Саме так реалізується завдання «Знайти першого відмінника» у практичній частині.

2 Цикл For…Next — сума та середнє
  1. Відкрийте вкладку Розробник → Макроси (або натисніть Alt + F8).
  2. Введіть ім'я макроса ОбчисленняСумаСереднє → «Створити».
  3. Вставте код нижче.
  4. Виконайте макрос: Розробник → Макроси → «Виконати».
Sub ОбчисленняСумаСереднє()
    Dim i As Integer
    Dim сума As Double
    Dim кількість As Integer
    Dim середнє As Double

    сума = 0
    кількість = 0

    ' Цикл For…Next для обчислення суми та кількості оцінок
    For i = 2 To 11   ' Рядки 2-11 (оскільки 1-й рядок - заголовки)
        If Cells(i, 3).Value <> "" Then
            сума = сума + Cells(i, 3).Value
            кількість = кількість + 1
        End If
    Next i

    ' Обчислення середнього
    If кількість > 0 Then
        середнє = сума / кількість
    Else
        середнє = 0
    End If

    ' Виведення результатів
    Range("F2").Value = "Сума оцінок:"
    Range("G2").Value = сума
    Range("F3").Value = "Кількість учнів:"
    Range("G3").Value = кількість
    Range("F4").Value = "Середній бал:"
    Range("G4").Value = Round(середнє, 2)

    MsgBox "Обчислення завершено! Сума: " & сума & _
           ", Середнє: " & Round(середнє, 2)
End Sub
Що відбувається

Лічильник i пробігає значення 2…11. Для кожного рядка перевіряється, чи є оцінка, і якщо є — вона додається до суми, а лічильник кількості збільшується на 1. Наприкінці обчислюється середнє.

3 Цикл For…Next з кроком — підвищення оцінок
  1. Створіть макрос ПідвищенняОцінок.
  2. Вставте наведений код.
  3. Виконайте макрос.
Sub ПідвищенняОцінок()
    Dim i As Integer
    Dim оцінка As Integer
    Dim новаОцінка As Integer

    ' Цикл For…Next для підвищення оцінок на 1 бал (максимум 12)
    For i = 2 To 11
        оцінка = Cells(i, 3).Value

        If оцінка >= 1 And оцінка <= 11 Then
            новаОцінка = оцінка + 1
        Else
            новаОцінка = оцінка   ' 12 залишається 12
        End If

        Cells(i, 4).Value = новаОцінка
    Next i

    MsgBox "Оцінки підвищено!"
End Sub
4 Цикл Do While…Loop — обробка до порожньої клітинки
  1. Створіть макрос ОбробкаДоПустого.
  2. Вставте код.
  3. Виконайте макрос.
Sub ОбробкаДоПустого()
    Dim i As Integer
    Dim оцінка As Integer

    i = 2   ' Починаємо з рядка 2

    ' Цикл Do While…Loop – виконуємо, поки клітинка не порожня
    Do While Cells(i, 2).Value <> ""
        оцінка = Cells(i, 3).Value

        ' Додаємо коментар залежно від оцінки
        If оцінка >= 10 Then
            Cells(i, 5).Value = "Відмінно"
        ElseIf оцінка >= 7 Then
            Cells(i, 5).Value = "Добре"
        ElseIf оцінка >= 4 Then
            Cells(i, 5).Value = "Задовільно"
        Else
            Cells(i, 5).Value = "Потрібна допомога"
        End If

        i = i + 1   ' Важливо! Інакше буде нескінченний цикл
    Loop

    MsgBox "Оброблено " & i - 2 & " учнів"
End Sub
Ключовий момент

Рядок i = i + 1 є обов'язковим. Без нього умова циклу ніколи не стане хибною, і макрос зависне.

5 Цикл For Each…Next — форматування виділеного діапазону
  1. Створіть макрос ФорматуванняДіапазону.
  2. Вставте код.
  3. Виділіть стовпець B або C з оцінками та виконайте макрос.
Sub ФорматуванняДіапазону()
    Dim cell As Range

    ' Перевірка, чи щось виділено
    If Selection.Count = 1 And Selection.Value = "" Then
        MsgBox "Будь ласка, виділіть діапазон з оцінками!"
        Exit Sub
    End If

    ' Цикл For Each…Next для обробки кожної виділеної клітинки
    For Each cell In Selection
        If IsNumeric(cell.Value) And cell.Value <> "" Then
            If cell.Value >= 10 Then
                cell.Interior.Color = RGB(0, 255, 0)      ' Зелений
            ElseIf cell.Value >= 7 Then
                cell.Interior.Color = RGB(255, 255, 0)    ' Жовтий
            ElseIf cell.Value >= 4 Then
                cell.Interior.Color = RGB(255, 165, 0)    ' Помаранчевий
            Else
                cell.Interior.Color = RGB(255, 0, 0)      ' Червоний
            End If
        End If
    Next cell

    MsgBox "Форматування завершено!"
End Sub

6 Цикл Do Until…Loop — пошук першого відмінника
  1. Створіть макрос ПошукВідмінника.
  2. Вставте код та виконайте макрос.
Sub ПошукВідмінника()
    Dim i As Integer
    Dim знайдено As Boolean

    i = 2
    знайдено = False

    ' Цикл Do Until…Loop – виконуємо, поки не знайдемо оцінку 12
    Do Until знайдено = True
        If Cells(i, 3).Value = 12 Then
            знайдено = True
            MsgBox "Відмінник знайдений у рядку " & i & ": " & Cells(i, 2).Value
            Cells(i, 3).Select
        Else
            i = i + 1
        End If

        ' Якщо дійшли до кінця таблиці, виходимо
        If i > 100 Then Exit Do
    Loop

    If Not знайдено Then
        MsgBox "Відмінників не знайдено!"
    End If
End Sub
7 Вкладені цикли — таблиця множення
  1. Створіть макрос ТаблицяМноження.
  2. Вставте код та виконайте макрос.
Sub ТаблицяМноження()
    Dim i As Integer
    Dim j As Integer

    ' Очищаємо аркуш "Таблиця" або створюємо новий
    On Error Resume Next
    Application.DisplayAlerts = False
    Sheets("Таблиця").Delete
    Application.DisplayAlerts = True
    On Error GoTo 0

    Sheets.Add After:=Sheets(Sheets.Count)
    ActiveSheet.Name = "Таблиця"

    ' Заголовки рядків (1-10)
    For i = 1 To 10
        Cells(i + 1, 1).Value = i
    Next i

    ' Заголовки стовпців (1-10)
    For j = 1 To 10
        Cells(1, j + 1).Value = j
    Next j

    ' Вкладений цикл для заповнення таблиці множення
    For i = 1 To 10
        For j = 1 To 10
            Cells(i + 1, j + 1).Value = i * j
        Next j
    Next i

    ' Форматування заголовків
    Range(Cells(1, 1), Cells(1, 11)).Font.Bold = True
    Range(Cells(1, 1), Cells(11, 1)).Font.Bold = True

    Cells(1, 1).Value = "×"
    Columns("A:K").AutoFit

    MsgBox "Таблиця множення створена на аркуші 'Таблиця'!"
End Sub
Вкладений цикл

Зовнішній цикл i відповідає за рядки, внутрішній j — за стовпці. Для кожного значення i внутрішній цикл повністю проходить усі 10 значень j. Разом — 10 × 10 = 100 клітинок.

9 Додаткове — параметричний цикл
  1. Створіть макрос ГнучкийЦикл.
  2. Вставте код та виконайте макрос — введіть початок, кінець і крок у діалогових вікнах.
Sub ГнучкийЦикл()
    Dim початок As Integer
    Dim кінець As Integer
    Dim крок As Integer
    Dim i As Integer

    ' Запитуємо параметри циклу
    початок = InputBox("Введіть початкове значення:")
    кінець = InputBox("Введіть кінцеве значення:")
    крок = InputBox("Введіть крок:")

    If початок = "" Or кінець = "" Or крок = "" Then
        MsgBox "Операцію скасовано"
        Exit Sub
    End If

    ' Цикл із введеними параметрами
    For i = початок To кінець Step крок
        Cells(i, 1).Value = i
    Next i

    MsgBox "Цикл виконано від " & початок & " до " & кінець & " з кроком " & крок
End Sub
