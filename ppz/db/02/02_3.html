1. Основні поняття БД: таблиця, поле, запис

Рис. 1. Структура таблиці БД: поля (стовпці) та записи (рядки)

📊 Таблиця

Основний об'єкт БД для зберігання даних. Складається з рядків та стовпців, організованих за певною структурою.

📏 Поле

Стовпець таблиці, який містить однотипні дані (наприклад, «Прізвище», «Дата_народження», «Телефон»).

📝 Запис

Рядок таблиці, який містить дані про один конкретний об'єкт (наприклад, інформацію про одного учня).

Рис. 3. Інтерфейс LibreOffice Base з основними елементами

Способи створення таблиці

🔧 Режим конструктора

Повний контроль над структурою: імена полів, типи даних, обмеження, ключі. Найбільш гнучкий спосіб.

🧙 Майстер

Покроковий діалог з попередньо визначеними шаблонами полів. Зручно для початківців.

📝 Режим таблиці

Швидке створення з миттєвим введенням даних. Типи полів визначаються автоматично.

🔗 Зв'язки між таблицями (ER-діаграма)

Рис. 4. ER-діаграма: зв'язок «один-до-багатьох» між таблицями «Учні» та «Батьки»

⚠️ Важливо!

Первинний ключ (PK) — поле, яке унікально ідентифікує кожен запис у таблиці. Він не може бути порожнім (NULL) і повинен бути унікальним. Зовнішній ключ (FK) — поле, яке забезпечує зв'язок між таблицями, посилаючись на первинний ключ іншої таблиці.

📋 Покрокова інструкція

Частина A. Створення бази даних
Запустіть LibreOffice Base → Створіть нову базу даних → Збережіть як Прізвище_ПЗ10_контакти.odb
Частина B. Таблиця «Учні»
Таблиці → Створити в режимі конструктора → Введіть поля: Код_учня, Прізвище, Ім'я, Клас, Дата_народження, Телефон, Email
Код_учня → INTEGER, Автозначення → Первинний ключ → Зберегти як «Учні»
Частина C. Таблиця «Батьки»
Створіть таблицю в режимі конструктора → Поля: Код_батька, Код_учня, Прізвище_батька, Ім'я_батька, Телефон_батька, Ступінь_споріднення
Код_батька → Первинний ключ → Зберегти як «Батьки»
Частина D. Введення даних
Відкрийте «Учні» → введіть 3-5 записів → Відкрийте «Батьки» → введіть 3-5 записів
Частина E. Сортування та фільтрація
Відсортуйте «Учні» за прізвищем → Відфільтруйте «Учні» за класом 3-А
Частина F. Завершення
Збережіть базу даних → Закрийте LibreOffice Base
