Основи автоматизації завдань в командному рядку

Створення простих скриптів і пакетних файлів (.bat / .cmd) для автоматизації рутинних операцій та використання планувальника завдань для їх автоматичного виконання.

1

Знання CLI: Узагальнити знання про основні команди текстового інтерфейсу.

2

Інженерне мислення: Розвиток навичок створення програмних сценаріїв (пакетних файлів).

3

Відповідальний підхід: Дотримання правил безпеки під час роботи з файловою системою.

1. Інтерактивний Довідник Команд CLI

Порівняння команд Windows CMD та Linux / macOS Terminal

ls / dir Перегляд

Список вмісту каталогу

Виводить список файлів та папок в поточному каталозі.

> dir C:\Users
cd Навігація

Change Directory

Переміщення між каталогами файлової системи.

> cd Documents
mkdir / md Створення

Make Directory

Створює нову папку з вказаною назвою.

> mkdir NewFolder
rm / del Видалення

Remove / Delete

Видаляє вказаний файл з диска.

> del file.txt
cp / copy Копіювання

Copy File

Копіює файл у вказану директорію.

> copy file.txt ..\backup
mv / move Переміщення

Move File

Переміщує або перейменовує файл.

> move file.txt archive\
cat / type / more Вміст

View File Content

Виводить вміст файлу прямо у консоль.

> type file.txt
grep / findstr Пошук

Text Search

Шукає фрагмент тексту всередині файлів.

> findstr "word" file.txt

2. Архітектура Пакетних Файлів (.bat / .cmd)

Кроки створення та ключові оператори Windows Scripting Language

Життєвий цикл розробки скрипта

Спеціальні оператори:
  • @echo off – приховує дублювання введених команд.
  • REM – коментар (ігнорується під час виконання).
Перенаправлення потоків:
  • > – перезапис виводу у файл.
  • >> – додавання виводу в кінець файлу.
⏱

Планувальник завдань

Task Scheduler (Windows)

Спеціальний інструмент ОС, який дозволяє налаштувати автоматичне виконання створених .bat скриптів за розкладом (наприклад, щодня о 00:00 для резервного копіювання).

💡 Автоматизація зменшує людський фактор та пришвидшує системне обслуговування!

3. Практичний Симулятор CLI та Скрипту

Виконайте завдання у віртуальному терміналі або запустіть пакетний скрипт

myscript.bat 
@echo off
REM Крок 1: Створення нового каталогу "MyScriptFolder"
mkdir MyScriptFolder

REM Крок 2: Перехід до нового каталогу
cd MyScriptFolder

REM Крок 3: Створення файлу "hello.txt" та запис рядка
echo Hello, it's my first script > hello.txt

REM Крок 4: Виведення списку файлів у каталозі
dir

REM Крок 5: Завершення скрипта
@echo on

5. Застереження та Безпека

Важливі правила під час роботи зі скриптами автоматизації

⚠️

Правила безпечного запуску:

1. Перевіряйте команди перед запуском: Скрипт автоматично виконує всі команди з правами вашого користувача без додаткового підтвердження.

2. Обережно з командами видалення: Команди на кшталт del /f /s /q або rm -rf видаляють файли безповоротно (оминаючи Корзину!).

3. Тестуйте у безпечному каталозі: Завжди виконуйте перші тести .bat файлу в окремо створеній порожній папці.
