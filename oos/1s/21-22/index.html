Основи операційних систем

Команди для роботи з текстовими файлами

Тема: Команди для роботи з текстовими файлами. Вивчення команд для перегляду, редагування та створення текстових файлів. Використання команди find для пошуку інформації у текстових файлах.

Мета: ознайомити з командами type, more, find, copy con, edit для роботи з текстовими файлами в командному рядку. Розвивати навички пошуку та фільтрації текстової інформації за допомогою команди find та шаблонів. Виховувати інформаційну грамотність та вміння ефективно працювати з текстовими даними.

Обладнання: інструкційні картки, персональні комп'ютери.

Хід заняття

Теоретичні відомості

У командному рядку Windows (cmd) для роботи з текстовими файлами використовується низка вбудованих команд. Вони дозволяють створювати, переглядати, редагувати та шукати інформацію у файлах без графічного інтерфейсу.

Основні команди для роботи з текстовими файлами

Команда Призначення Приклад
type Виведення вмісту текстового файлу на екран type readme.txt
more Посторінковий перегляд вмісту файлу more readme.txt
find Пошук рядка (слова, фрази) у файлі find "звіт" data.txt
copy con Створення текстового файлу з клавіатури copy con note.txt
edit Вбудований текстовий редактор (за наявності) edit note.txt
del Видалення файлу del note.txt
ren Перейменування файлу ren note.txt note2.txt

Команда type

Виводить вміст текстового файлу на екран. Синтаксис:

TYPE [шлях\]<ім'я файла>

Якщо файл великий, вміст «пролітає» дуже швидко. Для посторінкового перегляду використовують команду more.

Команда more

Виводить вміст файлу посторінково — після заповнення екрана чекає натискання будь-якої клавіші.

MORE [шлях\]<ім'я файла>

Команда find

Шукає заданий рядок у файлі або в потоці даних. Синтаксис:

FIND [/V] [/C] [/N] [/I] "рядок" [шлях\]<ім'я файла>

Ключі:

  • /V — виводить рядки, які не містять заданий рядок;
  • /C — виводить лише кількість рядків, що містять рядок;
  • /N — виводить номери рядків разом із вмістом;
  • /I — ігнорує регістр літер під час пошуку.

Приклад: find /N /I "звіт" data.txt — знайде всі рядки, що містять слово «звіт» (у будь-якому регістрі), і покаже їхні номери.

Команда copy con

Створює новий текстовий файл безпосередньо з клавіатури:

COPY CON <ім'я файла>

Після введення команди набирають текст, а завершують введення натисканням Ctrl+Z та Enter.

Команда edit

Вбудований текстовий редактор MS-DOS (у сучасних версіях Windows може бути відсутнім). Дозволяє створювати та редагувати файли:

EDIT [<ім'я файла>]
У сучасних Windows команда edit часто недоступна. Замість неї можна використовувати notepad <ім'я файла>.

Команда findstr (розширений пошук)

Сучасна альтернатива find з підтримкою регулярних виразів та шаблонів:

FINDSTR [/I] [/N] "шаблон" <ім'я файла>

Наприклад, findstr /I "звіт.*2024" data.txt знайде рядки, що містять «звіт» та «2024».

Практичні завдання

Завдання поділені на три рівні складності. Загальний час виконання — до 30 хвилин. Виконуйте завдання послідовно, починаючи з базового рівня.

Базовий Знайомство з командами перегляду та створення ⏱ 10 хв
  1. Відкрийте командний рядок (Win+R → cmd).
  2. Перейдіть у власну папку (наприклад, cd %USERPROFILE%).
  3. Створіть новий текстовий файл info.txt за допомогою команди copy con. Введіть 3–4 рядки довільного тексту (наприклад, своє прізвище, ім'я, групу). Завершіть введення Ctrl+Z та Enter.
  4. Перегляньте вміст файлу командою type info.txt.
  5. Перегляньте вміст файлу посторінково командою more info.txt.
  6. Скопіюйте файл у новий info_backup.txt командою copy.
  7. Перейменуйте info_backup.txt у backup.txt командою ren.
Середній Пошук та фільтрація за допомогою find ⏱ 10 хв
  1. Створіть файл students.txt командою copy con з таким вмістом (кожен рядок — окремий запис):
    Іваненко Іван, група 21 Петренко Петро, група 21 Сидоренко Оксана, група 22 Коваленко Марія, група 21 Шевченко Тарас, група 22
  2. Знайдіть усі рядки, що містять «група 21», командою find "група 21" students.txt.
  3. Знайдіть усі рядки, що містять «Петренко», із номерами рядків: find /N "Петренко" students.txt.
  4. Порахуйте кількість рядків зі словом «група»: find /C "група" students.txt.
  5. Знайдіть рядки, що не містять «група 22»: find /V "група 22" students.txt.
  6. Виконайте пошук без урахування регістру: find /I "іван" students.txt.
Просунутий Комбінування команд і шаблонів ⏱ 10 хв
  1. Створіть файл report.txt з кількома рядками, що містять дати у форматі 2024-01-15, 2024-02-20, 2023-12-05 та довільний текст.
  2. Знайдіть усі рядки, що містять «2024», командою find "2024" report.txt.
  3. Скомбінуйте find із перенаправленням виводу у файл:
    find "2024" report.txt > result.txt
  4. Перегляньте result.txt командою type.
  5. Використайте findstr для пошуку рядків, що починаються з «2024»: findstr /B "2024" report.txt.
  6. Знайдіть рядки, що містять або «звіт», або «report» (без урахування регістру): findstr /I "звіт report" report.txt.
  7. Створіть файл final.txt, об'єднавши info.txt та students.txt: copy info.txt + students.txt final.txt. Перегляньте результат.
  8. Видаліть тимчасові файли result.txt та backup.txt командою del.

Порада: якщо команда find не знаходить кириличні символи, спробуйте findstr або змініть кодування консолі командою chcp 65001 (UTF-8).
