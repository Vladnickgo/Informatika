1 Робота з контурами в Inkscape

У векторному редакторі Inkscape всі об'єкти (кола, прямокутники, лінії) є контурами — математичними кривими Безьє, які описують форму. Меню «Контури» (Path) містить набір операцій для комбінування та зміни цих форм.

Ключові можливості меню «Контури»

Таблиця 1. Базові операції з контурами
Операція Гарячі клавіші Результат
Object to Path Shift+Ctrl+C Перетворює фігуру (коло, прямокутник) на редагований контур
Stroke to Path Ctrl+Alt+C Перетворює обведення (лінію) на окремий контур із заливкою
Trace Bitmap Shift+Alt+B Відкриває діалог трасування растрового зображення
Union (Сума) Ctrl++ Об'єднує два об'єкти в один
Difference (Різниця) Ctrl+- Віднімає верхній об'єкт від нижнього
Intersection (Перетин) Ctrl+* Залишає лише спільну область перекриття
Exclusion (Виключення) Ctrl+^ Об'єднує об'єкти, видаляючи область перекриття

2 Логічні операції над контурами

Розглянемо кожну операцію наочно. Колір нової фігури успадковується від нижнього об'єкта.

2.1. Сума (Union)

→

Результат: об'єднання двох фігур в одну. Колір та обведення успадковуються від нижнього об'єкта. У прикладі — фіолетове коло та зелене коло (прямокутник) об'єдналися у фіолетову фігуру.

2.2. Різниця (Difference)

→

Результат: від нижнього об'єкта «відрізається» область перекриття з верхнім. Нова фігура отримує колір нижнього (червоного) трикутника.

2.3. Перетин (Intersection)

→

Результат: залишається лише спільна область перекриття. У прикладі — ромб.

2.4. Виключення (Exclusion)

→

Результат: об'єкти об'єднуються, але спільна область (перекриття) видаляється, утворюючи «порожнечу».

Важливо! При виконанні операцій завжди враховуйте порядок шарів. Верхня фігура впливає на нижню, а колір результату береться від нижньої. Якщо потрібно змінити результат — перемістіть фігуру на передній/задній план.

3 Трасування растрових зображень (Trace Bitmap)

Трасування (векторизація) — процес перетворення растрового зображення (пікселів) на векторні контури (криві).

Основні режими Trace Bitmap

Таблиця 2. Режими трасування
Режим Призначення Коли використовувати
Brightness cutoff Перетворює зображення в чорно-біле за порогом яскравості Чорно-білі логотипи, силуети, іконки
Edge detection Виявляє контури (краї) об'єктів Зображення з чіткими межами, лінійна графіка
Color quantization Зменшує кількість кольорів до заданої Кольорові логотипи з обмеженою палітрою
Порада: Для досягнення найкращого результату експериментуйте з параметром Threshold (поріг). Значення 0.450–0.650 дають оптимальний баланс деталізації та чистоти контуру.

Покрокова інструкція трасування

Крок 1: Імпорт

Відкрийте Inkscape, перетягніть растрове зображення (логотип) на полотно або використайте File → Import.

Крок 2: Вибір інструменту

Виділіть зображення, перейдіть у меню Path → Trace Bitmap (або Shift+Alt+B).

Крок 3: Налаштування

Виберіть режим (Brightness cutoff для ч/б), налаштуйте Threshold, увімкніть Live Preview для попереднього перегляду.

Крок 4: Застосування

Натисніть Update, потім OK. Векторний об'єкт з'явиться поверх оригіналу — перетягніть його вбік.

Крок 5: Редагування

Видаліть оригінальне растрове зображення. Векторний контур можна редагувати інструментом Node Editor (N).

4 Практичне завдання

Завдання

Створити векторне зображення логотипа з наданого растрового зразка (зображення орла/герба).

Порядок виконання

Підготовка

Завантажте зображення логотипа (надається викладачем). Перегляньте відеоінструкцію до виконання роботи.

Трасування

Виконайте трасування зображення за допомогою Path → Trace Bitmap. Налаштуйте поріг для отримання чистого контуру.

Редагування контуру

Видаліть зайві вузли, згладіть криві, приберіть артефакти трасування. Використовуйте Node Editor (N).

Художнє оформлення

Застосуйте градієнтну заливку, налаштуйте прозорість, додайте ефекти (наприклад, розмиття або тінь).

Збереження

Збережіть файл у форматі .svg та .png. Надішліть роботу на перевірку.

Критерії оцінювання: точність передачі форми, чистота контуру (відсутність зайвих вузлів), художнє оформлення (градієнти, прозорість), завершеність роботи.

? Контрольні запитання

Натисніть на запитання, щоб побачити відповідь.

Що таке контур у векторній графіці?
Контур — це математично описана крива (зазвичай крива Безьє), яка визначає форму об'єкта. У Inkscape будь-яка фігура (коло, прямокутник) може бути перетворена на контур для подальшого редагування.
Яка різниця між операціями «Сума» та «Перетин»?
«Сума» (Union) об'єднує два об'єкти в один, зберігаючи всі їхні частини. «Перетин» (Intersection) залишає лише спільну область перекриття двох фігур, відсікаючи все інше.
Як визначається колір нової фігури після застосування операції?
Колір заливки та обведення успадковується від нижнього об'єкта (того, що знаходиться на задньому плані).
Що таке трасування (векторизація) і для чого воно потрібне?
Трасування — це процес перетворення растрового зображення (пікселів) у векторні контури. Воно дозволяє масштабувати зображення без втрати якості, редагувати форму та зменшувати розмір файлу.
Який режим трасування найкраще підходить для чорно-білого логотипу?
Режим Brightness cutoff (поріг яскравості) — він перетворює зображення на чорно-біле, залишаючи лише контури з яскравістю вище заданого порогу.
Які гарячі клавіші викликають діалог Trace Bitmap?
Shift+Alt+B
Як змінити порядок об'єктів для отримання потрібного результату операції?
Використовуйте команди Object → Raise (Page Up) та Object → Lower (Page Down) або комбінації Home/End для переміщення на передній/задній план.
Що таке градієнтна сітка (Gradient Mesh)?
Це інструмент, який дозволяє створювати плавні переходи кольорів у кількох напрямках одночасно, на відміну від лінійного чи радіального градієнта. Використовується для реалістичного затінення об'єктів.
