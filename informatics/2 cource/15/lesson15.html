1. Зовнішні джерела даних

Сучасна програма рідко працює ізольовано. Вона постійно обмінюється інформацією із зовнішнім світом: отримує погоду, читає дані з датчиків, завантажує новини, реагує на дії користувача.

Зовнішні джерела даних

— це будь-які джерела інформації, розташовані поза межами самої програми: файли на диску, бази даних, вебсервери, сенсори, датчики, інші програми тощо.

🌐

Веб-API

Погода, курси валют, карти, соціальні мережі.

📁

Файли та БД

Локальні файли CSV, JSON, XML, бази даних.

🌡️

Сенсори та датчики

Температура, вологість, рух, звук, світло.

👆

Введення користувача

Клавіатура, миша, тачскрін, камера, мікрофон.

2. Дані сенсорів та датчиків

Сенсор (від лат. sensus — відчуття) — пристрій, що перетворює фізичні величини (температуру, тиск, освітленість) на електричні сигнали, які може обробити комп'ютер.

3. Прикладний програмний інтерфейс (API)

API (Application Programming Interface)

— це набір правил і протоколів, за допомогою яких одна програма може запитувати дані або послуги в іншої програми.

Уявіть API як меню в ресторані: ви (програма-клієнт) не йдете на кухню (сервер), а замовляєте страву через офіціанта (API). Офіціант приносить вам готову страву (дані) у зрозумілому вигляді.

🔧 Порада Найпопулярніший формат передачі даних через API — JSON (JavaScript Object Notation). Він читається і людиною, і машиною.

Приклади популярних API:

  • OpenWeatherMap — дані про погоду в будь-якій точці світу.
  • Google Maps API — карти, маршрути, геокодування.
  • Telegram Bot API — створення чат-ботів.
  • Wikipedia API — отримання статей енциклопедії.

4. Графічний інтерфейс користувача (GUI)

GUI (Graphical User Interface)

— це спосіб взаємодії користувача з програмою через графічні елементи: вікна, кнопки, меню, слайдери, поля введення тощо.

Для створення GUI в середовищі Processing існує кілька бібліотек. Підключити їх можна через меню: Скетч → Імпорт бібліотеки → Додати бібліотеку.

⚠️ Важливо! У цьому занятті ми використовуємо бібліотеку ControlP5. Її офіційна документація та приклади: sojamo.de/libraries/controlP5

5. Інтерактивні інсталяції

Інтерактивна інсталяція

— це мистецький або дизайнерський проект, який реагує на дії глядача (рух, звук, дотик) і змінюється в реальному часі.

Інсталяція поєднує сенсори, програму та візуальне/звукове відображення. Глядач стає співавтором твору.

🎨

TeamLab (Японія)

Імерсивні виставки, де квіти розквітають від дотику відвідувачів.

🎵

Звукові інсталяції

Музика, що генерується залежно від рухів тіла танцівника.

💡

Світлові проєкції

Проєкції на будівлях, що реагують на погоду або перехожих.

🤖

Роботизовані скульптури

Об'єкти, що рухаються у відповідь на присутність людей.

💡 Запам'ятай! Інтерактивна інсталяція = Сенсор (збирає дані) + Програма (обробляє дані) + Відображення (звук, зображення, рух).

💻 Приклади коду

Приклад 1. Створення кнопки в ControlP5

Цей приклад створює вікно з кнопкою. При натисканні на кнопку колір фону змінюється на випадковий.

import controlP5.*;

ControlP5 cp5;
color myColor = color(255);
color c1;
int n;

void setup() {
  size(400,600);
  cp5 = new ControlP5(this);
  // створення кнопки 'colorA': позиція (100,100), розмір 200×19
  cp5.addButton("colorA")
     .setValue(0)
     .setPosition(100,100)
     .setSize(200,19);
}

void draw() {
  background(myColor);
  myColor = color(c1);
}

// обробник подій від елементів керування
public void controlEvent(ControlEvent theEvent) {
  println(theEvent.getController().getName());
  n = n+1;
}

// функція, що викликається при натисканні кнопки colorA
public void colorA() {
  println("a button event from colorA: "+n);
  c1 = color(int(random(255)),int(random(255)),int(random(255)));
}
🔍 Пояснення ключових рядків
  • import controlP5.*; — підключаємо бібліотеку.
  • cp5 = new ControlP5(this); — створюємо об'єкт керування інтерфейсом.
  • addButton("colorA") — створюємо кнопку з іменем "colorA".
  • setPosition(100,100) — координати верхнього лівого кута кнопки.
  • setSize(200,19) — ширина 200, висота 19 пікселів.
  • Функція colorA() автоматично викликається при натисканні кнопки з таким самим ім'ям.

Приклад 2. Створення слайдера

Слайдер дозволяє користувачеві змінювати яскравість фону в діапазоні 0–255.

import controlP5.*;

ControlP5 cp5;
int sliderValue = 100;

void setup() {
  size(700,400);
  noStroke();
  cp5 = new ControlP5(this);
  // горизонтальний слайдер, діапазон 0-255
  cp5.addSlider("sliderValue")
     .setPosition(100,50)
     .setRange(0,255);
}

void draw() {
  background(sliderValue);
  fill(sliderValue);
  rect(0,0,width,100);
}
🔍 Пояснення ключових рядків
  • addSlider("sliderValue") — створюємо слайдер, прив'язаний до змінної sliderValue.
  • setRange(0,255) — задаємо діапазон значень від 0 до 255.
  • Коли користувач рухає слайдер, змінна sliderValue автоматично оновлюється.
  • У draw() ця змінна використовується для встановлення кольору фону.

Соціальна функція: мотивує до добрих вчинків, об'єднує колектив.
